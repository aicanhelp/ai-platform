# UB-Enable-Sig 快速开始仓

## 介绍

欢迎您访问openFuyao UB-Enable-Sig开发者Quick Start仓库，与我们一起完善开发者文档和示例代码。

## 开发者文档 (docs)

开发者文档在`docs`目录中，包含以下几部分：

- **specification**：规范和核心概念，让你了解整体设计意图和业务逻辑
- **quickstart**：10分钟完成第一个小demo
- **api**：提供每个API的参数、返回值等，供开发者参考
- **tutorial**：针对常见的用例场景，提供端到端代码示例

## 场景示例代码 (examples)

场景示例代码在`example`目录中，目前有如下样例（后续补充更多）：

- **flink_statebackend_require_more_memory**：借Flink的statebackend简化场景演示内存借用用法
- **spark_broadcastjoin_by_shared_memory**：借Spark的BroadcastJoin场景演示共享内存用法
