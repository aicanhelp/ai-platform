# Web Terminal Service

## Feature Introduction
Web Terminal is typically part of extensive cloud services or web-based services, allowing users to access command-line interfaces through web browsers. This is a virtual terminal that typically manages containers, services, applications, or databases directly through the web interface, without the need for local terminal emulation software or Secure Shell (SSH) clients. This feature is typically used to manage resource objects in the cluster, reducing dependence on local tools and simplifying the operation and maintenance process of Kubernetes clusters.

## Installation Deployment
On the openFuyao platform, Web Terminal provides an interactive CLI interface for the platform. This feature is deployed as a core component along with the [openFuyao platform](https://docs.openfuyao.cn/en/docs/v26.03/installation_guide/before_you_start.html), currently supporting management operations for entering clusters and containers.

## Local Build

### Image Build

#### Build Parameters

- `GOPRIVATE`: Configure Go language private repository, equivalent to the `GOPRIVATE` environment variable.
- `COMMIT`: Hash value of the current git commit.
- `VERSION`: Component version.
- `SOURCE_DATE_EPOCH`: Timestamp of the image rootfs.

#### Build Commands

- Build and push to specified OCI repository.

  <details open>
  <summary>Using <code>docker</code></summary>

  ```bash
  docker buildx build . -f <path/to/dockerfile> \
      -o type=image,name=<oci/repository>:<tag>,oci-mediatypes=true,rewrite-timestamp=true,push=true \
      --platform=linux/amd64,linux/arm64 \
      --provenance=false \
      --build-arg=GOPRIVATE=gopkg.openfuyao.cn \
      --build-arg=COMMIT=$(git rev-parse HEAD) \
      --build-arg=VERSION=0.0.0-latest \
      --build-arg=SOURCE_DATE_EPOCH=$(git log -1 --pretty=%ct)
  ```

  </details>
  <details>
  <summary>Using <code>nerdctl</code></summary>

  ```bash
  nerdctl build . -f <path/to/dockerfile> \
      -o type=image,name=<oci/repository>:<tag>,oci-mediatypes=true,rewrite-timestamp=true,push=true \
      --platform=linux/amd64,linux/arm64 \
      --provenance=false \
      --build-arg=GOPRIVATE=gopkg.openfuyao.cn \
      --build-arg=COMMIT=$(git rev-parse HEAD) \
      --build-arg=VERSION=0.0.0-latest \
      --build-arg=SOURCE_DATE_EPOCH=$(git log -1 --pretty=%ct)
  ```

  </details>

  Where `<path/to/dockerfile>` is the Dockerfile path, `<oci/repository>` is the image address, and `<tag>` is the image tag.

### Helm Chart Build
- Package Helm Chart.

  ```bash
  helm package <path/to/chart> -u \
      --version=0.0.0-latest \
      --app-version=openFuyao-v25.09
  ```

  Where `<path/to/chart>` is the Chart folder path.

- Push Chart package to specified OCI repository.

  ```bash
  helm push <path/to/chart.tgz> oci://<oci/repository>:<tag>
  ```

  Where `<path/to/chart.tgz>` is the Chart package path, `<oci/repository>` is the Chart package push address, and `<tag>` is the Chart package tag.

## Security Capabilities

openFuyao v26.06 and earlier versions only provide basic security features: mutual TLS (mTLS) between services and component-level user authentication and authorization (RBAC). Users and integration partners need to adapt and harden these capabilities according to their own deployment environments (e.g., introducing cert-manager, setting up unified certificates, deploying authentication middleware, and configuring NetworkPolicy to narrow the reachable scope). The current release focuses on delivering core functionality; security hardening is the responsibility of users. Security capabilities will be gradually planned and rolled out in subsequent versions.
