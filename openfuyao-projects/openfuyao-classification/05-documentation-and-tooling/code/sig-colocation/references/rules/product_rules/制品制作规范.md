# 1 制品定义文件命名规范

Helm Chart制品对应的定义文件需要存放在`charts/<chart_name>`目录下。其中`<chart_name>`为Helm Chart名称，命名规范为：`[a-z0-9](-[a-z0-9])*`。

镜像制品对应的定义文件需要存放在`build`目录下。若仓库中只包含一个镜像制品，则定义文件应命名为`Dockerfile`或`dockerfile`；否则，定义文件应命名为`<image_base_name>.dockerfile`。其中`<image_base_name>`为镜像名称中不包含`/`的最长后缀，命名规范为：`[a-z0-9]+((\.|_|__|-+)[a-z0-9]+)*`。

代码仓库目录结构示例如下：

```txt
repository/
├── build/
│   ├── container-1.dockerfile
│   ├── container-2.dockerfile
│   └── ...
├── charts/
│   ├── chart-1/
│   │   ├── charts/
│   │   ├── crds/
│   │   ├── templates/
│   │   ├── Chart.yaml
│   │   ├── README.md
│   │   ├── values.yaml
│   │   ├── values.schema.json
│   │   └── ...
│   └── chart-2/
│   │   └── ...
├── src/
│   └── ...
├── LICENSE
├── README.md
└── ...
```

# 2 镜像定义文件编写规范

openFuyao社区为主流编程语言提供了包含`ONBUILD`命令的编译时基础镜像，用于规范化制品构建流程，并确保安全编译选项处于开启状态。同时，为了最小化制品镜像，节约存储空间，openFuyao社区基于是否静态构建以及运行时依赖也提供了不同的运行时基础镜像。现根据以上两种镜像提供Dockerfile模板作为参考，具体镜像使用方式参见[`base-images`](https://gitee.com/openfuyao/base-images)。

```dockerfile
COPY --link --from=build --chmod=555 /go/bin/app entrypoint
ENTRYPOINT ["/entrypoint"]
```

# 3 Helm Chart定义文件编写规范

Helm Chart的`values.yaml`文件需要包含镜像信息字段，该字段下需要指定`repository`、`tag`、`digest`字段用于校验。`repository`字段需要按照统一格式填写：`harbor.openfuyao.com/openfuyao/<image_base_name>`，其中`<image_base_name>`为镜像制品名称。`digest`字段可以通过`docker image ls --digests`或`docker buildx imagetools inspect <image_name>`获取。

`values.yaml`示例如下：

```yaml
images:
  component-1:
    repository: harbor.openfuyao.com/openfuyao/component-1
    tag: latest
    digest: cd99675e534c8a4315ae42c86fcafa56132dc037245b13d3cdde686f467e2012
```

主分支中`Chart.yaml`文件中`version`字段固定为`0.0.0-latest`，`appVersion`字段固定为`latest`；版本分支中`version`和`appVersion`字段由Release SIG定义。

当主chart依赖subchart的时候，应将subchart存放在`charts/<chart_name>/charts/<subchart_name>`目录下，并在`dependencies`字段中定义subchart信息。若subchart可复用，或与主chart所在代码仓库关联性不高，则应将subchart提出，作为独立chart存放在其他仓库`charts/<chart_name>`目录下。

`Chart.yaml`示例如下：

```yaml
apiVersion: v2
name: foo-chart
version: 0.0.0-latest
appVersion: latest
dependencies:
  - name: foo-chart-bar-local
    version: 0.0.0-latest
  - name: foo-chart-baz-https
    version: 0.10.0
    repository: https://harbor.openfuyao.com/chartrepo/openfuyao
  - name: foo-chart-qux-oci
    version: 0.10.0
    repository: oci://harbor.openfuyao.com/openfuyao/charts
```

为了避免pod的容器以root用户运行，需要在工作负载资源（如：`Pod`、`Deployment`等）定义中添加`securityContext`字段，并在该字段下添加`runAsUser`/`runAsGroup`字段并指定非root用户/组，建议大于3000（如：65532）。以`Pod`资源为例：

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: security-context-demo
spec:
  securityContext:
    runAsUser: 65532
    runAsGroup: 65532
  volumes:
  - name: sec-ctx-vol
    emptyDir: {}
  containers:
  - name: sec-ctx-demo
    image: busybox:1.28
    command: [ "sh", "-c", "sleep 1h" ]
    volumeMounts:
    - name: sec-ctx-vol
      mountPath: /data/demo
```
