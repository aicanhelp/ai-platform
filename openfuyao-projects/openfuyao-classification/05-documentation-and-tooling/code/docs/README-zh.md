# README

## 介绍

欢迎您访问openFuyao官方文档仓库，参与openFuyao开发者文档开源项目，与我们一起完善开发者文档。

openFuyao docs仓包含了openFuyao社区的所有文档，如发行说明、产品描述、快速入门、安装指导等内容。

## openFuyao文档

openFuyao官网地址：<https://openfuyao.cn/zh/>

openFuyao文档地址：<https://gitcode.com/openFuyao/docs>

## 参与贡献

欢迎您参与文档贡献，文档开发请关注[写作规范](./contribute/zh/writing_specifications.md)和[markdown常用语法参考](./contribute/zh/common_markdown_syntax_reference.md)。

您还可以对现有文档进行评价、简单更改、反馈文档质量问题、贡献您的原创内容。可以参考以下贡献方式：

- **建立或回复issue**：欢迎通过建立或回复issue参与讨论和贡献。

- **提交PR**：欢迎通过提交PR的方式参与贡献。

- **提交评论**：欢迎在issue或PR中提交评论。

详细贡献方式请参见[贡献文档](./contribute/zh/contributing_documents.md)。
