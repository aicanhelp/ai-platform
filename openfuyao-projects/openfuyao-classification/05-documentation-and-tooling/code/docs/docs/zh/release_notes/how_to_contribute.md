# 参与贡献

## 参与贡献

作为openFuyao的用户，您可以通过多种方式协助openFuyao社区。参与社区贡献的方法请参见[贡献攻略](https://www.openfuyao.cn/zh/contribution/)。这里简单列出部分方式供参考。

### 特别兴趣小组

openFuyao将拥有共同兴趣的人们聚在一起，组成了不同的特别兴趣小组（SIG）。当前已有的SIG请参见[SIG列表](https://www.openfuyao.cn/zh/sig/sig-list/)。

### 邮件列表和任务

欢迎您积极地帮助用户解决在[邮件列表](https://www.openfuyao.cn/zh/email/)和issue任务（包括[代码仓任务](https://gitcode.com/org/openFuyao/issues)）中提出的问题。另外，我们也欢迎您提出问题。这些都将帮助openFuyao社区更好地发展。

### 文档

您不仅可以通过提交代码参与社区贡献，我们也欢迎您反馈遇到的问题、困难，或者对文档易用性、完整性的改进建议等。例如获取软件或文档过程中的问题，使用过程中的难点。欢迎关注并改进openFuyao社区的文档模块。
