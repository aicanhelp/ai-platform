# openFuyao资源获取

openFuyao提供了丰富的线上资源，在使用中遇到的任何问题，您都可以在官方网站进行查找。同时，也可以通过开源社区、邮件列表及其他学习交流平台将您遇到的问题与其他openFuyao使用者进行交流和分享。

## 官网

[openFuyao官网](https://openfuyao.cn/zh/)提供了openFuyao软件的下载、官方文档、贡献地图、活动及资讯等信息。

- 下载：下载openFuyao社区发行版与特性组件，获取应用中心、镜像中心等丰富资源。
- 项目：了解openFuyao核心能力与关键技术项目，涵盖NUMA亲和调度、在离线混部调度、AI分布式作业调度、AI推理一键部署等算力调度与优化能力，以及NPU Operator、KAE Operator等多样化算力资源池化管理组件。
- 学习：提供文档、课程视频以及用户案例资源，一站式助您快速上手与进阶。
- 支持：关注社区公告，掌握安全动态与漏洞应对；获取FAQ等服务支持，快速解决问题。
- 社区：了解openFuyao社区运作章程、贡献参与流程，帮助您参与SIG项目，参与贡献。
- 动态和交流：提供社区最新动态，浏览博客、新闻、月刊与年报以及峰会等活动信息，参与邮件列表和在线会议，随时与我们联系。

## openFuyao SIGs

openFuyao社区通过SIGs（Special Interest Groups）进行组织和管理，按照不同职能划分成多个SIG组。SIG组是开放的，欢迎任何人加入并参与贡献，每个SIG在gitcode上有一个或多个仓库。您可以在SIG对应的代码仓库上提交Issue，参与Issue讨论，提交Pull Request，参与代码检视等。常用SIG见[表1](#table123400789)，您可以从SIG说明列表中找到您感兴趣的SIG。参与贡献的方法请参见[社区贡献](https://openfuyao.cn/zh/contribution/)。

**表 1** openFuyao社区SIG<a id="table123400789" href="#"></a>

| SIG名称                 | 职责范围                                    |
| :---- | :---- |
| TC                      | 筹备委员会例行运作承载平台。   |
| QA                      | 负责openFuyao版本测试质量，构建openFuyao社区整体测试能力及测试规范。 |
| security-committee                | 负责openFuyao社区网络安全防护能力构建，制定安全测试规范，漏洞安全响应/漏洞处理及漏洞激励计划等网络安全活动。         |
| release-management                 | 负责openFuyao社区的版本计划管理、社区版本的发布、软件包的管理等。           |
| docs                    | 负责openFuyao社区整体技术文档、运营相关文档的输出和发布。         |
| sig-container-platform | 负责openFuyao社区容器集群编排、监控、告警、调度等技术方向的能力构建，技术规划及决策。 |
| sig-orchestration-engine         |负责openFuyao社区容器编排引擎创新能力的构建与技术讨论。 |
| sig-installation               | 负责openFuyao解决方案版本各类场景下安装部署能力的构建，支撑客户界面简单易用的、一键执行的安全部署能力的提供。 |
| sig-ai-inference              | 负责openFuyao社区AI推理加速能力的构建与技术讨论。 |

## 博客

openFuyao提供了[博客](https://openfuyao.cn/zh/blogs/)页面，汇总了openFuyao用户在使用及开发中遇到的各类问题及经验分享。当您在使用过程中遇到任何问题，可在博客页面进行搜索，查看其他用户的解决方法。也欢迎您分享在使用过程中的使用心得，帮助其他人解决相关问题。
