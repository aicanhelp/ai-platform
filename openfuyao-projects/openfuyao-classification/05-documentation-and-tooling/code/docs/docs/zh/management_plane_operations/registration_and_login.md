# 注册和登录

## 创建账号

安装部署成功后，默认创建“admin”用户，初始临时登录密码为“test@1234”。

> ![输入图片说明](figures/iconnote.gif)**说明：**
>
> - 修改用户描述信息和密码请参见[修改密码](./getting_started.md#修改密码)或[用户管理](./user_management.md#使用用户视角的用户管理)。
> - 为保证账号的安全性，请定期（如六个月）修改密码。

## 登录平台

1. 浏览器输入“https://_管理面的客户端登录IP地址_:_openFuyao的web服务端口_”。
2. 输入用户名和密码，单击“登录”，进入openFuyao平台总览页。

> ![输入图片说明](figures/iconnote.gif)**说明：**
>
> - 首次登录时需要修改密码。
> - PC分辨率支持1920 x 1080和1280 x 1024，推荐使用最优分辨率为1920 x 1080。
> - openFuyao的web服务端口安装完成后默认为31616。
