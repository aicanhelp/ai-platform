# 总览

左侧导航栏中单击“总览”，进入“总览”界面。总览页展示了openFuyao平台各资源、组件的实时状态。

**表 2** 概览页面各区域参数说明

| 名称         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 节点         | 当前集群的节点数量及状态。                                   |
| 管理节点     | 管理节点的总数及异常节点的数量。                             |
| 工作节点     | 工作节点的总数及异常节点的数量。                             |
| 命名空间     | 当前集群包含的命名空间（namespace）总数。                    |
| 服务账户     | 集群中服务账户（serviceaccount）的总数。                     |
| 角色         | 集群中角色（role）的总数。                                   |
| Pod          | 集群中Pod的数量及状态，状态包含Running、Pending、Succeeded。 |
| 告警         | 集群中当前告警的数量，包含三个严重等级：严重、警告、提示。   |
| 应用         | 集群中当前部署的应用数量及状态，应用状态包含三种：部署成功、处理中、失败。 |
| 扩展组件     | 集群中当前部署的扩展组件数量及状态，扩展组件状态包含三种：部署成功、处理中、失败。 |
| 工作负载     | 集群中当前部署的工作负载的数量及状态，工作负载的类型包含三种：Deployment、StatefulSet、DaemonSet；状态包含三种：Active、Updating、Failed。 |
| 资源统计     | 集群硬件资源的统计数据，包含CPU、内存、存储。对于CPU、内存给出了使用率、请求率和限制率，存储给出了磁盘空间使用率和inode使用率。并且给出了对应使用率的top5图例，可选择统计时间查看对应图例。 |
| 网络负载Top5 | 展示流量Top5的节点及Pod，可查看流入流量及流出流量。          |
