# Obtaining openFuyao Resources

openFuyao provides abundant online resources. For any problems encountered during use, you can search for solutions on the official website. In addition, you can communicate and share your problems with other openFuyao users through the open-source community, mailing lists, and other learning and communication platforms.

## Official Website

The [openFuyao official website](https://openfuyao.cn/en/) provides access to openFuyao software downloads, official documentation, contribution maps, events, and news.

- Download: Download the openFuyao community edition and feature components, and access abundant resources from the application center and image center.
- Projects: Explore openFuyao's core capabilities and key technology projects, covering NUMA-aware scheduling, colocation scheduling, AI distributed job scheduling, AI inference one-click deployment, and other compute scheduling and optimization capabilities, as well as diversified compute resource pooling management components such as NPU Operator and KAE Operator.
- Learn: Provides documentation, course videos, and user case resources for quick start and advanced learning in one stop.
- Support: Follow community announcements, stay updated on security dynamics and vulnerability responses; obtain service support such as FAQ to quickly resolve issues.
- Community: Learn about the openFuyao community charter and contribution process, helping you participate in SIG projects and contributions.
- Updates & Communication: Provides the latest community updates, browse blogs, news, monthly reports and annual reports, as well as summit and other event information. Participate in mailing lists and online meetings to stay connected with us.

## openFuyao SIGs

The openFuyao community is organized and managed through SIGs (Special Interest Groups), which are divided into multiple SIG groups based on different functions. SIG groups are open to everyone to join and contribute. Each SIG has one or more repositories on gitcode. You can submit Issues, participate in Issue discussions, submit Pull Requests, and participate in code reviews on the SIG's code repository. Common SIGs are listed in [Table 1](#table123400789). You can find the SIGs you are interested in from the SIG description list. For how to participate in contributions, see [Community Contribution](https://openfuyao.cn/en/contribution/).

**Table 1** openFuyao Community SIGs<a id="table123400789"></a>

| SIG Name | Scope of Responsibilities |
| :---- | :---- |
| TC | The designated platform for the routine operations of the openFuyao Preparatory Committee. |
| QA | Responsible for openFuyao version testing quality, building overall testing capabilities and specifications for the openFuyao community. |
| security-committee | Responsible for building network security protection capabilities for the openFuyao community, establishing security testing specifications, security response to vulnerabilities, vulnerability handling, and vulnerability incentive programs and other network security activities. |
| release-management | Responsible for version plan management, community edition releases, and software package management for the openFuyao community. |
| docs | Responsible for the output and release of overall technical documents and operations-related documents for the openFuyao community. |
| sig-container-platform | Responsible for building capabilities, technical planning, and decision-making for container cluster orchestration, monitoring, alerting, and scheduling in the openFuyao community. |
| sig-orchestration-engine | Responsible for building innovation capabilities and technical discussions for container orchestration engines in the openFuyao community. |
| sig-installation | Responsible for building installation and deployment capabilities for openFuyao solution versions in various scenarios, providing simple, easy-to-use, one-click secure deployment capabilities for customers. |
| sig-ai-inference | Responsible for building AI inference acceleration capabilities and technical discussions in the openFuyao community. |

## Blog

openFuyao provides a [blog](https://openfuyao.cn/en/blogs/) page, which aggregates various problems and experience sharing encountered by openFuyao users during use and development. When you encounter any problems during use, you can search the blog page to find solutions from other users. You are also welcome to share your experience during use to help others solve related problems.

## Mailing List

The openFuyao community uses a [mailing list](https://openfuyao.cn/en/email/) for online communication. We sincerely invite you to participate in discussions through the [mailing list](https://openfuyao.cn/en/email/).
