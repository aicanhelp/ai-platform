# Registration and Login

## Creating an Account

After the installation and deployment are successful, the **admin** user is created by default, and the initial temporary login password is **test@1234**.

> ![Input image description](figures/iconnote.gif)**Note:**
> 
> - For details about how to change the user description and password, see [Changing a Password](./getting_started.md#changing-a-password) or [Managing a User](./user_management.md#managing-account-information-as-a-user).
> - To ensure account security, change the password periodically (for example, every six months).

## Logging In to the Platform

1. Enter "https://_client login IP address of the management plane_:_openFuyao web service port_" in the address box of a browser.
2. Enter the username and password, and click **Log In**. The openFuyao platform overview page is displayed.

> ![Input image description](figures/iconnote.gif)**Note:**
> 
> - Changing the password is required upon the first login.
> - Two display resolution options are offered: 1920 x 1080 and 1280 x 1024. The optimal resolution 1920 x 1080 is recommended.
> - The default web service port of openFuyao after installation is **31616**.
