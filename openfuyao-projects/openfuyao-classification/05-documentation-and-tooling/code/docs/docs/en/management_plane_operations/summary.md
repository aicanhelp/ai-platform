# Summary

In the left navigation pane, click **Summary**. The **Summary** page is displayed. This page displays the real-time status of each resource and component on the openFuyao platform.

**Table 2** Metrics in different areas on the Summary page

| Name| Description|
|----------|----------|
| Nodes| Number and status of nodes in the current cluster.|
| Master nodes| Total number of master nodes and number of abnormal nodes.|
| Worker Nodes| Total number of worker nodes and number of abnormal nodes.|
| Namespaces| Total number of namespaces in the current cluster.|
| ServiceAccounts| Total number of service accounts in the cluster.|
| Roles| Total number of roles in the cluster.|
| Pods| Number and status of pods in the cluster. The status can be **Running**, **Pending**, or **Succeeded**.|
| Alerts| Number of alerts in a cluster. The severity can be **Critical**, **Warning**, or **Information**.|
| Applications| Number and status of applications currently deployed in the cluster. The application status can be **Succeeded**, **Handling**, or **Failed**.|
| Extensions| Number and status of extensions currently deployed in the cluster. The extension status can be **Succeeded**, **Handling**, or **Failed**.|
| Workloads| Number and status of workloads currently deployed in the cluster. The workload type can be **Deployment**, **StatefulSet**, or **DaemonSet**. The workload status can be **Active**, **Updating**, or **Failed**.|
| Resource Statistics| Statistics of hardware resources in the cluster, including the CPU, memory, and storage. For the CPU and memory, the usage, request percentage, and limit rate are provided. For the storage, the disk space usage and inode usage are provided. In addition, legends for top 5 resources with the highest usage are provided with selectable time ranges.|
| Network Load Top 5| Top 5 nodes and pods with the highest traffic are displayed. You can view the inbound and outbound traffic.|
