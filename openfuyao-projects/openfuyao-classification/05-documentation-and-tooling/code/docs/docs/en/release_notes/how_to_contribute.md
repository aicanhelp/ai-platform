# How to Contribute

## How to Contribute

As an openFuyao user, you can assist the openFuyao community in multiple ways. For methods to participate in community contributions, please refer to the [Contribution Guide](https://www.openfuyao.cn/en/contribution/). Here we briefly list some methods for your reference.

### Special Interest Groups

openFuyao brings together people with common interests and has formed various Special Interest Groups (SIGs). For currently existing SIGs, please refer to the [SIG List](https://www.openfuyao.cn/en/sig/sig-list/).

### Mailing Lists and Tasks

You are welcome to actively help users solve problems raised in the [mailing list](https://www.openfuyao.cn/en/email/) and issue tasks (including [code repository tasks](https://gitcode.com/org/openFuyao/issues)). Additionally, we also welcome you to raise questions. All of these will help the openFuyao community develop better.

### Documentation

You can contribute to the community not only by submitting code, but we also welcome your feedback on problems and difficulties you encounter, as well as suggestions for improving the usability and completeness of the documentation. For example, problems encountered during the process of obtaining software or documentation, and difficulties during use. You are welcome to follow and improve the documentation module of the openFuyao community.
