# README

## Introduction

Welcome to the openFuyao official documentation repository. Participate in the openFuyao developer documentation open source project and help us improve the developer documentation together.

The openFuyao docs repository contains all documentation of the openFuyao community, such as release notes, product descriptions, quick start guides, installation guides, and more.

## openFuyao Documentation

openFuyao official website: <https://openfuyao.cn/zh/>

openFuyao documentation: <https://gitcode.com/openFuyao/docs>

## Contributing

Welcome to participate in documentation contribution. For documentation development, please refer to [Writing Specifications](./contribute/en/writing_specifications.md) and [Common Markdown Syntax Reference](./contribute/en/common_markdown_syntax_reference.md).

You can also evaluate existing documents, make simple changes, feedback on documentation quality issues, and contribute your original content. You can refer to the following contribution methods:

- **Create or reply to issues**: Welcome to participate in discussions and contributions by creating or replying to issues.

- **Submit PRs**: Welcome to participate in contributions by submitting PRs.

- **Submit comments**: Welcome to submit comments in issues or PRs.

For detailed contribution methods, please see [Contributing Documents](./contribute/en/contributing_documents.md).
