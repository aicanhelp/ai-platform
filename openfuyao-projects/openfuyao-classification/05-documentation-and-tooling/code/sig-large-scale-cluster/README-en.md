# sig-large-scale-cluster

Welcome to sig-large-scale-cluster!

## Working Goals and Scope

- **Goals:** Dedicated to providing stable ultra-large-scale clusters, focusing on Kubernetes core component optimization, AI job scheduling optimization, and TCP store keychain optimization in a single cluster. Breaking through Kubernetes' declared multi-cluster limits, supporting 128k card (1.6w node) clusters. Facing future 50w card cluster scale, providing multi-cluster multi-level scheduling and other technologies to further improve scheduling performance.
- **Scope:** Focusing on network, monitoring, AI job scheduling, image pull acceleration, AI training stability improvement, Kubernetes core component optimization, and automated cluster deployment in ultra-large-scale scenarios.

## Organizational Regular Meetings

sig-large-scale-cluster is open. Our users, contributors, and maintainers continuously improve it. It is because of you that we can build a more stable and easy-to-use ultra-large-scale cluster. Join us!
