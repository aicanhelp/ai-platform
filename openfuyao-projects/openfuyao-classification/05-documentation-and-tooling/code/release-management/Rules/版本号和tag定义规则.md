# 版本号总体命名规则

形如\<MAJOR>.\<MINOR>.\<PATCH>\[-\<pre-release>]\[+\<build-metadata>]

其他说明：
1、候选版本仅openFuyao版本使用，组件不使用候选版本；
2、原则上补丁版本里只合入bugfix；
3、单组件的版本号规划由SIG组负责，openFuyao的版本号由RMSIG组负责
4、openFuyao的补丁版本是增量包，其他组件和openFuyao的版本都是全量包；

|对象(样例)|显示版本号(样例)|tag(样例)|
|--------------------------------------|-----------------|-----------------|
|openFuyao的正式Release版本|v25.09|25.09|
|openFuyao的候选版本|v25.09-rc.1|25.09-rc.1|
|openFuyao的补丁|v25.09.1|25.09.1|
|单组件版本（也包括helmchart版本号）|x.y.z|x.y.z|
|.......1)首次推出的版本/即试用版本(x从0编码)|0.y.z|0.y.z|
|.......2)已经正式可商用的版本(x从1开始编码)|x(x>=1).y.z|x(x>=1).y.z|
|平行社区组件(有上游社区)的版本：基于原有版本号上后缀增加-of.z|上游社区版本-of.z|上游社区版本-of.z|
|.......1)例如：k8s|v1.33.1-of.1|1.33.1-of.1|
