# 3. 特性分层测试方案

## 3.1 总体方案

- 工作量估算：
  *（基于用例密度参考值估算。每千行代码约15.7~36.8个用例，结合特性代码量和测试类型给出预估工作量，为资源与时间协调提供依据。注意：测试应向测试经理如实反映达到目标保障程度所需的工作量，质量保障是前提，资源与时间的妥协由测试经理和版本经理协调。）*

- 入口标准：
  1. 特性满足转测质量要求（详见[《社区质量标准》](../docs/社区质量标准.md)）
  2. 特性级测试用例已完成评审
  3. 所有P0/P1级用例已执行并通过
  4. DT覆盖率达标（成熟特性>80%，孵化期>40%）

- 出口标准：
  1. 方案规划的测试活动涉及测试用例100%执行完毕
  2. 无block问题遗留，其它遗留问题要有相应规避措施或说明
  3. 无安全红线问题遗留
  4. 自动化率>80%（转测一周内）
