# v26.09-KubeOS安装部署适配-特性测试报告

# 1     特性概述

本特性实现 openFuyao 平台在安装部署阶段适配 KubeOS，支持普通 openEuler master/control-plane 与 KubeOS worker VM 共存的混合 OS 集群形态。通过 `--immutable-os=kubeos` 参数触发 KubeOS 适配安装逻辑，worker 节点使用 KubeOS VM 镜像启动，跳过只读目录二进制安装，仅保留配置渲染和状态初始化，集群安装完成后通过 KubeOS addon 接管 worker 节点的 OS 生命周期管理（升级/回滚/配置）。


## 1.1 特性清单

| ofep编号 | 特性名称 | SIG组 | 特性描述 |
| ------ | -------- | ----- | -------- |
| oFEP-TBD | KubeOS 安装部署适配 | sig-installaton | 安装部署阶段适配 KubeOS，支持 CLI `--immutable-os` 参数注入、worker 跳过二进制安装仅保留配置渲染、webhook 角色冲突校验、KubeOS addon 安装调度，实现普通 openEuler master + KubeOS worker 混合 OS 集群 |

## 3.2   约束说明

- master 节点不支持运行 KubeOS，不支持容器 OS 升级；
- worker 节点必须通过 KubeOS VM 镜像创建，不接受普通 openEuler 节点加入 KubeOS worker 池；
- 不支持普通 openEuler worker 在线转换为 KubeOS worker；
- `--immutable-os` 参数仅对 worker 节点生效，master 节点始终走普通 openEuler 安装流程；
