# v26.09-ServerlessDB-Operator-特性测试报告

# 1     特性概述

ServerlessDB Operator 是面向 AI Agent 场景的数据库管控面组件，基于 K8s Operator 扩展机制，定义数据库实例资源 CRD（DBResourcePool、DBInstance），实现数据库计算实例的预热资源池管理、实例生命周期管理（申请/释放/垂直扩缩容）以及连接地址（Service）管理。

## 1.1 特性清单

| ofep编号 | 特性名称 | SIG组 | 特性描述 |
| ------ | ---------------------- | -------- | ---- |
| ofep-0056 | Serverless DB Operator | sig-orchestration-engine | 基于 K8s Operator 机制实现数据库计算实例的预热资源池管理、实例申请/释放/垂直扩缩容、连接地址管理及认证鉴权能力 |

## 3.2   约束说明

- 数据库存算分离由数据面实现，不在本组件范围内；
- 数据库实例使用普通容器，不提供安全隔离；
- 实例垂直扩缩容能力依赖 K8s InPlacePodVerticalScaling 特性（1.32 版本为 Alpha），当前仅对外提供接口，实际扩缩效果受集群特性启用状态影响；
- 数据库连接地址不变，但数据库连接会中断，需要客户端重新触发连接；
