# v26.06版本agent沙箱特性测试报告

# 1  特性概述

agent沙箱特性面向 Sandbox 生命周期中的状态保存、归档持久化和从归档恢复能力。该特性通过 Checkpoint Controller 触发节点侧 checkpoint，通过 Node Agent 管理快照归档上传、下载和清理，并在 Restore 流程中由 Sandbox Controller 识别 restore 注解、创建带快照信息的 Pod，再由 kata-shim 在目标节点调用 Node Agent 下载快照并完成 microVM 恢复准备。
