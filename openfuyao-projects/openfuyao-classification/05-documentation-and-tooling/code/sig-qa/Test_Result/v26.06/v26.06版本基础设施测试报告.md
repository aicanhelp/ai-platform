# v26.06版本基础设施测试报告

# 1  特性概述

本报告涵盖 openFuyao 平台基础设施相关功能测试，包括基础设施运营能力优化（支持页面评分、文档搜索功能优化、支持文档捉虫、官网内容优化）和基础设施工程能力优化（门禁流水线支持Python语言UT检查、流水线效能指标看板、组件发行版支持自动发布、日构建流水线支持E2E离线测试用例）。
