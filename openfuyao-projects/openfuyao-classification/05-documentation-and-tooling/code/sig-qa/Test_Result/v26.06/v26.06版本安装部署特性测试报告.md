# v26.06-安装部署-特性测试报告

# 1     特性概述

本版本安装部署特性的核心目标是实现架构演进，将版本生命周期管理能力从安装部署流程中解耦独立，构建完整的版本管理、升级编排与兼容性保障体系，支持openFuyao core版本的平滑升级与动态运维。

## 1.1 特性清单

| 特性名称 | sig组 | 特性描述 |
| -------- | ---- | -------- |
| [安装部署]安装部署架构演进：支持openFuyao core版本生命周期管理 | sig-installation | **架构解耦**：将openfuyao-system-controller从安装部署模块移除，提供独立部署方案，实现版本管理与安装部署的职责分离；<br>**版本管理模型**：提供版本管理基础模型，支持版本清单的分发与存储，支持升级路径规划及版本的动态管理；<br>**升级任务编排**：支持升级任务的触发与调谐，提供组件升级插件框架和升级流程编排引擎，实现Phase适配与预创建资源机制；<br>**兼容与平滑升级**：提供版本组件兼容性校验能力，支持旧版到新版的平滑升级方案 |

# 3     测试结论概述

## 3.1   测试整体结论

安装部署特性新增代码总量15.2k，新增123个测试用例，共执行用例451个，主要覆盖了功能测试、集成测试、性能测试、兼容性测试、长稳测试和资料测试。用例执行100%，提交issue65个，目前无遗留问题待处理，专项测试结果均符合版本规划。

## 3.2   约束说明

特性使用时涉及到的约束及限制条件

| 约束 | 说明 |
| ------ | ------ |
| **1:1 映射** | 单集群活跃状态下，1 个 `ClusterVersion` 严格对应 1 个 `ReleaseImage` |
| **清单不可变** | `ReleaseImage.Spec` 创建后不可修改 |
| **向后兼容** | 必须支持从现有 `BKECluster` 平滑迁移，Feature Gate 控制开关 |
| **离线环境** | 所有资源通过 OCI/本地缓存提供，支持断网降级 |
