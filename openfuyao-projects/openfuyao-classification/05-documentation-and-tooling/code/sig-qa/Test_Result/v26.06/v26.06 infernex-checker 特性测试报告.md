# v26.06 infernex-checker 特性测试报告

# 1     特性概述

InferNex前置校验工具（infernex-checker）是一个独立的CLI（Command-Line Interface，命令行界面）工具，用于在执行helm install部署InferNex之前对目标环境进行系统性验证。该工具通过检测硬件、K8s集群及业务配置与环境匹配的关键环节，将环境问题的识别从运行时提前至部署前，有效降低部署失败风险并提升系统稳定性。
