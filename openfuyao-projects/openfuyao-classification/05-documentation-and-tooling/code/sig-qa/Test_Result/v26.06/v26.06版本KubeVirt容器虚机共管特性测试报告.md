# v26.06版本KubeVirt容器虚机共管特性测试报告

# 1  特性概述

KubeVirt 容器虚机共管特性基于原生 Kubernetes 机制扩展，将虚拟机 VM 与容器统一纳入 Kubernetes 声明式 API 和管理体系，使 VM 能够复用 Kubernetes 的编排、调度、网络与资源管理能力。本轮测试重点验证 KubeVirt 在鲲鹏 ARM64 节点上的部署运行、虚拟机基础生命周期管理、网卡热插拔、macvtap/macvlan、SR-IOV、SR-IOV 实时迁移、普通虚拟机热迁移，以及前端页面管理虚拟机能力。

# 3  测试结论概述

## 3.1   测试整体结论

KubeVirt 容器虚机共管特性共执行 18 条测试用例，其中自动化用例 12条，非自动化用例 6 条，主要覆盖了特性级集成测试和系统级集成测试，通过经过fuzz和7*24的长稳测试，发现问题已解决，回归通过，无遗留风险，整体质量良好。

本轮测试结论如下：

| 特性 | 用例数 | 测试结论 |
| ---- | ------ | -------- |
| 网卡热插拔能力 | 4 | Multus 相关组件可正常部署；运行中 VM 可新增、删除网卡；连续热插拔后状态一致 |
| macvtap/macvlan | 2 | macvtap CNI 可正常部署，设备可上报；VM 可分配 macvtap 设备并完成网络互通 |
| SR-IOV | 3 | sriov-network-operator 可正常部署，VF 设备可上报和分配；VF 资源不足时 VM 调度失败且不影响已有 VM |
| SR-IOV 实时迁移 | 4 | 特性门控可开启；静态 IP/MAC 迁移后保持；迁移后 VF 可清理回收；迁移失败时源 VM 和 VF 状态保持正确 |
| 虚拟机热迁移 | 1 | ARM64 VM 支持热迁移，迁移后 VM 运行节点切换，VM 内文件状态保持 |
| 支持界面管理虚机 | 4 | 页面支持 virtualmachines.kubevirt.io 资源展示、模板创建和开机/关机/重启操作 |
