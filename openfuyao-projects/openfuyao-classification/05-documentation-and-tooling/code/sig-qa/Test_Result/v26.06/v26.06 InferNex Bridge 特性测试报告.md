# v26.06 InferNex Bridge 特性测试报告

# 1     特性概述

InferNex Bridge是InferNex与KServe之间的核心枢纽，以Validating/Mutating Webhook与InferNexService CRD衔接两套部署入口，支持双模式部署策略：既可无缝融入现有KServe生态，也可在无KServe环境下独立运行。
