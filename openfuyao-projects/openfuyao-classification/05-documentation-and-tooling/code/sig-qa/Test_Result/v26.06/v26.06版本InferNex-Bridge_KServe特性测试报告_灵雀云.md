## 四、缺陷归属与处置

> 测试中暴露的问题按责任方分类,供发版评审判断是否阻断。

| 问题 | 归属 | 本发版状态 | 影响 / 处置 |
|---|---|---|---|
| 默认托管 Gateway class 写死 `envoy`(无 controller) | InferNex-Bridge 产品 | 物料侧已规避(用 `gateway.spec.gatewayClassName=aieg-1`) | 不阻断;建议产品默认值改为可配置 |
| OLM CSV mutating webhook 早期漏注册 `v1alpha2` | InferNex-Bridge 产品 | **本发版已修**(commit `3ec87d7`,webhook 现匹配 v1alpha1+v1alpha2) | 已闭环 |
| LLMISVC-PD 端到端推理依赖 KServe PD 路由(llm-d)+ 引擎偶发崩溃(堆内存损坏 / SIGABRT) | 上游(KServe / vllm-ascend / mooncake) | 存在 | 请求本身可 200(KV 传输实证),decode 处理后偶发崩溃自恢复;建议上游跟进 |
| eagleEye 依赖 NATS,集群未部署 | 环境依赖 | 存在 | FIT_30 阻塞;非产品缺陷,补 NATS 即可;不阻断发版 |
| 上游 4 条 E2E 用例未实现 | 上游用例缺失 | — | FIT_10/23/52/55 标 SKIP;可手工验证,不阻断 |
