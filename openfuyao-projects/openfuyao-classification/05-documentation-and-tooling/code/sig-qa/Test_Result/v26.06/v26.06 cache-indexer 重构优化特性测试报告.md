# v26.06 cache-indexer 重构优化特性测试报告

# 1     特性概述

cache-indexer是面向大语言模型推理场景的全局KVCache索引组件，统一维护L1（推理实例本地HBM）与L3（推理实例内存缓存）两层KVCache视图。路由组件可调用cache-indexer查询候选推理实例的KVCache命中率，从而进行更准确的请求级调度。
