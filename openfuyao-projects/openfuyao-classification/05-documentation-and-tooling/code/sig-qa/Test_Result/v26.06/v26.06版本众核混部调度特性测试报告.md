# v26.06版本众核混部调度特性测试报告

# 1  特性概述

Many-Core Orchestrator（MCO，众核调度编排系统）面向众核混部集群，提供宿主机干扰指标采集、节点干扰分析、Volcano 干扰感知调度，以及可选的 Kata Containers 虚拟机级隔离能力。该特性用于降低在线业务在 I/O、LLC 缓存和内存压力混部场景下的长尾延迟抖动，并提升节点安全混部密度。
