# 1     特性概述

安装部署特性是 openFuyao 一切的开始， 能够在各种软硬件环境下顺利的完成 openFuyao 集群安装部署至关重要。InferNex 则是 AI 推理核心组件，对 AI 推理赋能起着重要作用。本次测试着重关注 openFuyao 安装部署特性及 InferNex 特性，还有与之关联的 npu-operator 等特性。

```bash
# 安装bke
curl -sfL https://openfuyao.obs.cn-north-4.myhuaweicloud.com/openFuyao/bkeadm/releases/download/26.6.0-rc.2/download.sh | bash
curl -fL https://openfuyao.obs.cn-north-4.myhuaweicloud.com/openFuyao/bkeadm/releases/download/26.6.0-rc.2/bkeadm_linux_amd64 -o /usr/local/bin/bke

# 在线安装引导节点
bke init --onlineImage cr.openfuyao.cn/openfuyao/bke-online-installed:26.6.0-rc.2 --confirm

# 离线资源 yaml
wget https://raw.gitcode.com/openFuyao/release-management/blobs/f80773e70437d0da8fd23e51dea0817cad507eda/Core-VersionConfig-v26.06-rc.2.yaml

# 构建离线包
rm -rf /bke && bke build -f Core-VersionConfig-v26.06-rc.2.yaml -t bke.tar.gz

# 离线安装引导节点
rm -rf /bke && tar zxvf bke.tar.gz -C /
# 修改安装工具名称
ARCH=$(uname -m)
case $ARCH in
x86_64) ARCH="amd64";;
aarch64) ARCH="arm64";;
esac
mv /usr/local/bin/bkeadm_linux_$ARCH /usr/local/bin/bke
bke init
```
