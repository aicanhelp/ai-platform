# v26.06 elastic-scaler 增强特性测试报告

# 1     特性概述

当前版本elastic-scaler增强特性主要内容如下：
- 补齐用户可用的指标表达能力：新增 Custom 指标类型与 ExternalServer.query 可选字段，降低用户配置与理解成本，并提升对 custom.metrics.k8s.io 和 Prometheus 查询场景的适配能力。
- 为算法提供稳定一致的输入：细化 ContextBuilder、MetricsManager 的接口契约、组件边界与内部协作关系，明确指标采集、处理和上下文构建的责任分工。
