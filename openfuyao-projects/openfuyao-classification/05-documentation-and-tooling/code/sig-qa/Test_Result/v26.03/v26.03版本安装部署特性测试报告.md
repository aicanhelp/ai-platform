# v26.03版本安装部署特性测试报告


# 1 特性概述

|特性名称 | 描述 |
| -------- | ------------ |
| 前后置操作   | 支持创建节点前后置操作（shell）   |
| openfuyao组件提供Health接口   | 管理、业务集群的pod和系统服务支持健康检查   |
| 镜像仓介入   | 引导节点镜像、二进制取自自身registry   |
| BC拆分   | BKECluster的CR拆分出BKENode，cluster-api-provider-bke、bekcommon相关仓库进行重构适配   |
| 安装部署架构优化   | bke支持从多制品仓库拉取镜像，bke适配openfuyao25.12的k8s版本升级至1.34版本及配套，bke支持安装k8s版本同时兼容1.28，1.34版本   |
| chart形态插件安装   | 创建集群时addons支持插件chart安装   |
| victoriametrics，local-dns，calicowithtypha组件安装   | 提供各组件安装方式和使用说明   |
