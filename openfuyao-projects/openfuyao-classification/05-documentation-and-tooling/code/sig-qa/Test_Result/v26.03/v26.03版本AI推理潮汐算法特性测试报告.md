# v26.03AI推理潮汐算法特性测试报告


# 1     特性概述

Tidal是面向具有明显潮汐特征业务的定时扩缩容算法。用户通过编写Tidal CRD，在指定时间点将可扩缩容的目标工作负载（如Deployment、StatefulSet、ResourceScalingGroup等）扩/缩到指定副本数。当前版本主要考虑时间维度因素，适合业务负载规律清晰、可通过时间配置预先规划容量的场景。Tidal Controller只负责计算期望副本并写入状态字段，实际扩缩容由通用决策框架ElasticScaler执行。
