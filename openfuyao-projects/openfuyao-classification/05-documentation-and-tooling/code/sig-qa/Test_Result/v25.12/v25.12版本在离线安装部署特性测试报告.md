# 1     特性概述

# 3     测试结论概述

## 3.1   测试整体结论

本次测试主要的是在两个硬件环境下分别进行共部署验证，验证在主流架构和系统配合下在线和离线部署的特性正常。目前测试发现一些硬件和软件环境约束，排除后可以正常进行。

## 3.2   约束说明

经过测试发现软硬件环境具有以下约束：

- amd64 环境下若使用 VM 拉起 k8s 集群， 需要使用 `host` 类型的 CPU，若使用 `kvm64` 类型会出现 calico 启动异常；
- amd64/arm64 环境下进行离线包构建时， 需要确保 docker 版本不要太高。目前已知 docker 29 无法构建，docker 26 可以正常构建。
