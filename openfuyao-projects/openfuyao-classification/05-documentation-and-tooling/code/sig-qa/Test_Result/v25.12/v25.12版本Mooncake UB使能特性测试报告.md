# v25.12版本Mooncake UB使能特性测试报告


# 1     特性概述

在面向LLM 推理场景的分布式KVCache引擎Mooncake中，新增基于UB共享内存的逻辑内存池，通过UB设备实现跨节点内存访问，替代原有的网络数据传输，使Mooncake可利用下一代硬件的数据访问能力优化KVCache读写性能.

# 3     测试结论概述

## 3.1   测试整体结论

Mooncake UB使能特性共执行18个测试用例，覆盖Mooncake store接口测试与功能测试，验证该特性对Mooncake的修改未对本身可用性产生影响，并支持UB共享内存挂载。

## 3.2   约束说明

- 本特性的运行需要环境对UB的支持。
- 需要提供至少两台物理节点，以验证Mooncake客户端在单、多节点场景下基于Kubernetes for UB共享内存的KVCache读写。
