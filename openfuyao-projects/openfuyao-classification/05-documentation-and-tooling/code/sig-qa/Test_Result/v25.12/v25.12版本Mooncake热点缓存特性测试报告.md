# v25.12版本Mooncake热点缓存特性测试报告


# 1     特性概述

为Mooncake Store Client引入基于LRU（Least Recently Used）替换策略的热点数据缓存机制。该优化旨在提升内存利用效率，减少跨节点网络访问开销，增强热点数据的本地可用性，从而提升分布式KVCache存储的单键和批量获取操作性能。
