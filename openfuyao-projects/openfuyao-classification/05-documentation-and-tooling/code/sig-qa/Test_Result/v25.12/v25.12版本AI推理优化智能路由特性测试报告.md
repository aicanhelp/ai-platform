# v25.12版本AI推理优化智能路由特性测试报告


# 1     特性概述

开源网关集成与路由策略演进，实现服务请求级与实例请求级路由协同，开放成本函数配置和路由策略配置，提升易用性，降低TTFT，长短请求中高并发场景TPS提升20%。

# 3     测试结论概述

## 3.1   测试整体结论

AI推理优化智能路由特性，共计执行32+5个用例，主要覆盖了功能测试、集成测试和性能测试，通过经过fuzz和7*24的长稳测试，发现问题已解决，回归通过，无遗留风险，整体质量良好。

## 3.2   约束说明

本特性仅能够在拥有NPU资源的环境上使用。

## 3.3   遗留问题分析

当前版本该特性无遗留问题。
