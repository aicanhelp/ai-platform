
# QA SIG

The QA (Quality Assurance) project team tests the software released by the openFuyao community, with the goal of continuously improving the release quality of the openFuyao community and community testing capabilities.

Main activities include:

- Building community testing capabilities to enable more community developers to participate in, use, and contribute
- Developing testing tools to improve code development efficiency and test coverage
- Formulating test plans and planning corresponding testing activities based on version plans
- Formulating, publishing, and maintaining management version release standards
