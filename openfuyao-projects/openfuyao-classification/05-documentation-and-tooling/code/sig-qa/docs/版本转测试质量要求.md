| 编译错误清零   | 必须 | 社区Beta、Release版本属于正式版本，要求满足最基本的64位编程规范和质量要求 |
| 开源义务履行   | 必须 | 是否包含NOTICE文件、SCA是否合规等                       |
| 冒烟测试通过率  | 必须 | 通过率100%                                     |
| 安装部署     | 必须 | 基于社区安装部署要求通过验证                              |
| issue解决  | 必须 | 上版本遗留问题100%按原计划解决；严重/致命版本问题100%解决           |

|          |    | 提供社区新增需求完整清单；完成社区新增需求开发自检；                  |

|          |    | 提供完整的与上个转测版本的软件变化清单（新增/升降级/删除/发布位置变更及原因）    |
| 转测范围     | 必须 | 提供交付件清单、未交付件清单及未交付件未交付说明；                   |
