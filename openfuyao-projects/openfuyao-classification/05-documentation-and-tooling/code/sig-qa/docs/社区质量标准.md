# openFuyao社区质量标准

本文档是 openFuyao 社区测试质量指标的统一规范，涵盖版本出口标准、组件上车质量要求和特性转测质量要求。所有质量指标数值以本文档为唯一基准。

## 1. 版本阶段说明

| 分类说明 | 每日构建版本 | Beta版本 | 正式版本 |
|---------|------------|---------|---------|
| 能力目标 | 尝鲜版本，支持社区伙伴联调开发与验证 | 基本功能稳定，支持伙伴联调开发与验证 | 功能稳定，通过专项测试，符合社区质量要求 |
| 发布周期 | PR合入触发 | 3个月 | 3个月 |
| 获取渠道 | Harbor仓 | 由release SIG宣布进入beta期 | 社区正式公告 |

## 3. 版本出口标准

版本发布须同时满足以下条件：

1. 所有上车特性满足本文档第 2 节中对应版本阶段的质量要求
2. 版本通过兼容性测试、可靠性测试和系统级集成测试
3. 无安全红线问题遗留，无关键阻塞问题遗留

## 4. 组件上车质量要求

组件上车除满足第 2 节通用质量指标外，还须满足以下各测试类型的具体要求：

### 4.1 安装卸载测试

1. 能够通过应用市场进行扩展组件安装，并通过扩展组件管理或应用管理进行卸载
2. 能够通过helm工具进行独立安装与卸载

### 4.2 功能测试

基于特性需求，保障功能完整可用，冒烟测试100%通过。

- 开源需求全部实现并通过测试验证，满足产品对开源的性能、功耗等DFX要求。
- 不存在遗留的致命问题，且遗留的严重问题有解决方案和计划或规避措施。
- 计划对外开源的所有交付件已基线化（包括工程文档及其它文档）。
- 源码完整且一致，相同源码相同环境下，能够自动构建出相同的二进制文件，允许编译时间戳、编译链接顺序不同等因素导致的不一致。
- 满足需求E2E可追溯（从需求→代码→用例可追溯，所有变更受控并有记录）。

### 4.3 性能测试

构造合适的性能测试场景，构建性能基线，性能满足性能规格。

### 4.5 兼容性测试

描述兼容性规格，兼容操作系统范围、架构，及k8s版本范围。

### 4.6 生命周期

基于开源版和社区要求。

### 4.7 资料测试

1. 开源版本应输出用户指南、开发指南：
   a. 用户指南建议包括：软件的介绍、安装、部署等使用指导。
   b. 开发指南建议包括：源码编译构建指导、ChangeLog、开发状态、功能规范、API接口（输入和输出）的参考文档。
2. 用户文档中如涉及安全配置内容，则安全配置应参考安全SIG标准规范，并通过安全SIG评审。

### 4.8 升级

满足社区已发布的历史版本升级路径。

## 5. 特性转测质量要求

### 5.1 转测质量指标

详情见[转测验收checklist](转测验收checklist.md)

### 5.2 转测说明

1. 不一定等需求完全开发完成后才转测——能否转测，取决于当前特性的完成度能否支撑测试。
2. 如果一个需求在部分实现的情况下也能支撑测试，建议进行进一步的AR拆分，并明确不同的转测时间。
3. 同一需求转测两次的情况，需在转测邮件中明确。同一需求多次发送转测邮件时，度量数据以最后一次转测邮件为准。

## 6. 问题分级与打回规则

### 6.1 问题分级定义

| 级别 | 功能维度 | 性能维度 | 安全维度 |
|:-----|:---------|:---------|:---------|
| **严重** | 阻塞基础测试，导致核心/扩展组件不能提供正常服务 | 性能低于规格 >=30% | CVSS >=9 的CVE未修复 |
| **主要** | 需求明确要求的功能未实现或实现不正确，造成特性无法满足需求；或阻塞组件基础测试但不影响其他组件 | 性能低于规格 [20%,30%)；或长时间测试性能下降幅度>=5% | CVSS [7,9) 未修复；病毒木马；安全基线未通过；开源片段/License不合规 |
| **次要** | 规格实现有问题但未造成特性整体失效；或阻塞模块功能但不影响基础功能 | 性能低于规格 [10%,20%)；或长时间测试性能下降幅度 [0%,5%) | CVSS [4,7) 未修复；安全编译选项未使用；安全编码问题 |
| **不重要** | 拼写/UCD错误；易用性问题；功能优化建议 | 性能低于规格 [0%,10%) | CVSS [0,4) 未修复 |

### 6.2 转测验收打回规则

| 条件 | 处理 |
|------|------|
| P0/P1用例不通过 | 直接打回 |
| 验出严重问题，阻塞测试 | 直接打回 |
| 验出严重问题，未阻塞，但验收期内（3工作日）未闭环 | 打回 |
| DT覆盖率不达标 | v26.03视情况打回，v26.06起直接打回 |
