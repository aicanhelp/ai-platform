# Web控制台终端工具特性测试方案

# 1. 特性描述

*Web终端通常是更广泛的云服务或者基于Web服务的一部分，它是的用户能够通过Web浏览器访问命令行界面。这是一个虚拟终端，通常直接通过Web界面管理、应用程序或者数据库，无需本地终端仿真软件或安全外壳（SSH）客户端。*
*1130版本openFuyao平台增加了Web终端为平台提供了可交互的CLI界面，提供集群进入和容器进入的功能*
