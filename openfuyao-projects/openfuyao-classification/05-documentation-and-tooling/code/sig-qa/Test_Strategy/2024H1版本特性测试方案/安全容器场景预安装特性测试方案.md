## 2.2 功能测试

openFuyao基于安全容器预安装场景，此功能本版本主要为验证阶段，本版本不发布，只为下个版本做校验，相对独立。
目前暂时从文档上确定的为kuasar只支持物理机，且为openEuler23.03，还需开发验证，目前暂时以openEuler22.03测试为主，输出测试文档

设计思路：

| 正交因子   | 取值                                   | 交互策略 | 备注                                        |
| ---------- | -------------------------------------- | -------- | ------------------------------------------- |
| 操作系统   | openEuler22.03,ubuntu22.04             | 正交     | 目前不确定是否支持ubuntu，暂以openEuler为主 |
| 架构       | X86，ARM                               | 正交     |                                             |
| 全量       | 是，否                                 | 覆盖     |                                             |
| HA         | HA,noHA                                | 覆盖     |                                             |
| 场景       | 多节点，AIO                            | 覆盖     |                                             |
| 基本功能   | 功能检查（告警，日志，运行状态等检查） | 正交     |                                             |
| 可插拔组件 | 安装部署                               | 覆盖     |                                             |
| 安全容器   | 版本记录(isulad+kuasar+stratovirt)     | 正交     |                                             |
