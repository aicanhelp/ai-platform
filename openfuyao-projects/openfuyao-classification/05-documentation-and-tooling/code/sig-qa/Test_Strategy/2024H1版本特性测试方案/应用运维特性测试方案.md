# 应用运维特性测试方案



# 1. 特性描述

应用运维是平台的基础能力，用户需要方便地对应用进行各项运维操作，获取应用的基本信息，监控应用的状态，从而更好地利用平台进行服务管理。 如安装卸载等运维操作,查看应用的整体的状态，查看包含应用创建时间和访问地址的基本信息。同时要支持能够查看应用关联的k8s原生工作负载，显示应用对应的YAML文件和容器组信息。同时用户需要能够查看应用的所有事件，快速了解应用运行过程中发生的事件，并根据多个参数进行筛选，以便在出现问题时快速定位和解决问题。应用监控机制则保证了对应用的关键指标高效获取，例如CPU使用量、内存使用量、网络流量和磁盘读写速度进行持续监控，在到达预设的告警标准之后，向运维人员发送特定的告警信息，减少运维成本，保证整个集群能够更加高效地运转。

3. operator信息（details）获取接口，主要是基本信息，包含的资源（CRD），operator介绍，资源实例，事件：1个
4. CR详情信息的获取,主要是基本信息，介绍，资源，事件：1个
5. CR操作相关接口，对CR操作，创建，编辑，卸载一个CRD中的某个CR： 2个
6. event相关接口： 1个
7. subscription相关接口：1个
8. helm管理相关 查看helm详情接口： 1个
9. helm管理相关 helm升级接口： 1个
10. helm管理相关 helm回退接口： 1个
11. helm管理相关 删除helm接口： 1个
