# 资源管理特性测试方案

# 1. 特性描述

上个版本资源管理模块资源量少且资源操作不完整，只支持工作负载、配置、存储三种资源的查看操作，不能进行增删改操作，不方便用户从页面统一操作使用。为更好的支持Kubernetes资源调度，本版本openFuyao管理面需要支持资源增、删、改、查，并设计页面对用户使用进行指导，提升用户的使用体验，并且增加了涉及资源范围：Workloads、Setting、Networking、Storage、Compute、User Management、Administration。

## 1.1 特性清单

| IR编号 | 特性名称              | 特性描述                        | 开发团队 | 备注  |

## 2.3 自动化测试方案

接口文档：https://gitee.com/openfuyao/enhancements/blob/master/design/feature/%E8%B5%84%E6%BA%90%E7%AE%A1%E7%90%86%E7%89%B9%E6%80%A7%E8%AE%BE%E8%AE%A1%E8%AF%B4%E6%98%8E%E4%B9%A6/%E8%B5%84%E6%BA%90%E7%AE%A1%E7%90%86%E6%8E%A5%E5%8F%A3%E6%96%87%E6%A1%A3.md

测试设计思路：

本版本资源管理能力增强，需要确保对资源（工作负载、配置、集群管理、网络、用户管理）的增删改查接口正常，通过接口自动化测试能更方便快速检测系统接口是否正常运行。在设计过程中，详细理解接口文档给出的接口定义、请求参数、响应格式、各错误状态码等信息，保证在写用例的过程中，尽量全面覆盖各种情况。
