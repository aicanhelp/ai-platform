# 告警特性测试方案

# 1. 特性描述

Openfuyao告警系统可以通过配置不同的告警源（当前版本支持监控和日志可插拔组件）和告警规则，当集群发生故障时，能快速通知告警信息，方便用户定位异常。

## 1.1 特性清单

| IR编号 | 特性名称            | 特性描述                                                             | 开发团队  | 备注  |
| ---- | --------------- | ---------------------------------------------------------------- | ----- | --- |
| IR-4 | 提供平台基础能力-告警功能开发 | 平台核心能力，前台管理面提供单独告警页面，可以查看所有告警信息。告警范围覆盖监控、日志模块，告警信息的状态分为严重、告警、提示。 | *平台组* |     |

## 1.2 SR分解清单

| SR编号     | 需求描述                     | 关联功能       | 备注  |
| -------- | ------------------------ | ---------- | --- |
| SR-4-1-1 | 支持日志、监控作为告警源向告警模块发送告警信息  | 提供告警源管理功能  |     |
| SR-4-2-1 | 日志、监控模块增加告警规则查看功能        | 提供告警规则管理功能 |     |
| SR-4-2-2 | 日志、监控模块提供预置的告警规则         | 提供告警规则管理功能 |     |
| SR-4-3-1 | 增加告警信息查看功能               | 提供告警信息管理功能 |     |
| SR-4-3-2 | 管理平台显著位置提供告警信息概要情况实时感知功能 | 提供告警信息管理功能 |     |

  | 验证同一时间大量告警全部恢复，没有漏恢复的告警     | 构造对同一时刻大量告警进行恢复，查看是否全部恢复                              | 告警全部恢复                                                                    |                       |

测试设计思路：

630版本告警特性涉及获取告警列表、静默规则的增删查共7个接口。通过接口自动化测试能更方便快速检测功能接口是否正常运行。在自动化测试设计过程中，详细理解接口文档给出的接口定义、请求参数、响应格式、各错误状态码等信息，保证在写用例的过程中，尽量全面覆盖各种情况。
