#                在openFuyao中使用openEuler基础镜像特性测试方案

摘要：
本版本仅对Nginx进行容器镜像封装。若openFuyao安装中Host OS为openEuler，则平台启动过程中选择此镜像提供nginx服务。此Nginx镜像也会上传应用市场，作为openFuyao官方维护的中间件对外提供。

## 2.2 功能测试

目前计划直接使用openEuler社区提供的基于openEuler基础镜像制作的nginx镜像。

设计思路：

| 正交因子                                               | 取值                                                         | 交互策略 | 备注 |
| ------------------------------------------------------ | ------------------------------------------------------------ | -------- | ---- |
| openEuler社区提供的nginx镜像                           | openeuler/nginx:1.25.4-oe2203sp3，openeuler/nginx:1.21.5-22.03-lts | 正交     |      |
| 前台基于服务openEuler社区提供的nginx镜像打包生成的镜像 | arm，X86（打包使用的buildX指令同时生成ARM与X86镜像包）       | 正交     |      |
| 镜像包测试1                                            | 启动测试                                                     | 正交     |      |
| 镜像包测试2                                            | HTTP/HTTPS的响应测试                                         | 正交     |      |
| 镜像包测试3                                            | 使用性能测试工具对镜像包进行接口访问压力测试                 | 正交     |      |

|---------------|--------------------------------------------|------| --- |
| 打包镜像流程 | 前台服务基于openEuler社区提供的openEuler基础镜像制作的nginx镜像打包验证（ARM/X86） | 打包完成 |      |

- SR-8-1-1-2 稳定性验证

  openeuler/nginx:1.21.5-22.03-lts与openeuler/nginx:1.25.4-oe2203sp3打包成功率与镜像启动成功率比较

| 场景描述      | 测试设计方案                      | 预期结果 | 备注 |
|-----------|---------------------------|------| --- |
| openeuler/nginx:1.25.4-oe2203sp3 | 使用buildx指令打包在相同次数（50次）的情况下，验证基于此镜像（此镜像dockers file通过二进制make完成）与前台服务打包时的打包成功率测试，以及镜像启动成功率测试验证 | 打包或启动成功 | openEuler社区提供的镜像预计无法测出对比结果 |
| openeuler/nginx:1.21.5-22.03-lts | 使用buildx指令打包在相同次数（50次）的情况下，基于此镜像（此镜像打包dockers file通过yum安装完成）与前台服务打包时的打包成功率测试，以及镜像启动成功率测试验证。 | 打包和启动成功 | openEuler社区提供的镜像预计无法测出对比结果 |

| 性能对比测试       | 使用压测工具（Jmeter）进行接口访问压力测试，对比与官网的和openEuler的差距（ARM/X86） | 性能波动不大 |        |
