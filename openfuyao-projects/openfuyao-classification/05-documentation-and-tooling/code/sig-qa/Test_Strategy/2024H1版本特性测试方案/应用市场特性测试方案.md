# 应用市场特性测试方案



# 1. 特性描述

对openFuyao容器管理平台的用户来说，最核心的诉求是在其之上增加扩展组件能力以及运行工作负载，对openFuyao平台来说定义为扩展组件和用户应用。

为方便用户使用扩展组件与用户应用，openFuyao平台需要提供扩展组件市场与应用市场，openFuyao平台初始部署完毕后会自带一些基础的应用与扩展组件，用户也可以对扩展组件市场和应用市场进行扩充，增加来自用户的扩展组件与应用。

容器平台管理员可以从应用市场中选择需要部署的应用进行部署，也可以上传任何符合要求的应用到应用市场中。

容器平台管理员可以从扩展组件市场中选择扩展组件进行部署，或上传符合要求的扩展组件到扩展组件市场中。

# 2. 特性分层测试方案

## 2.1 总体方案

- 测试目标：验证应用市场特性的应用仓库支持（本地仓库、远端仓库、官方仓库），应用商店能力（搜索、筛选等），应用上传能力（应用/扩展组件，上传后在商店展示）等。

- 时间进度：

  | 开始日期 | 结束日期 | 工作日 | 阶段                                           | 备注 |
  | -------- | -------- | ------ | ---------------------------------------------- | ---- |
  | 4.1      | 5.10     |        | 特性开发+前后台联调                            |      |
  | 5.11     | 5.14     |        | 测试执行（功能、安全、自动化测试等）+issue提交 |      |
  | 5.15     | 5.25     |        | bug修复+回归验证                               |      |

- 风险评估：从开始转测到测试结束的时间跨度较短（5.11-5.25，11个工作日），需要执行各项测试、提交/跟踪issue、bug修复、回归验证等。所以需要测试团队在4月份进行充分准备（深入熟悉需求、细致的设计测试用例），防止测试时间不足导致测试不充分。

- 重点/难点：NA

- 待定事项：NA

- 入口标准：

  1. 特性满足质量标准，达成需求设计要求目标

- 出口标准：
  1. 方案规划的测试活动涉及测试用例100%执行完毕
  2. 无block问题遗留，其它遗留问题要有相应规避措施或说明
