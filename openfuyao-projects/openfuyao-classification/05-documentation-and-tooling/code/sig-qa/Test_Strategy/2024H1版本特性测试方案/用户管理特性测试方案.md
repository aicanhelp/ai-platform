# 用户管理特性测试方案

# 1. 特性描述

*openfuyao 0.5版本无用户认证功能，所有人都可以直接对系统进行操作，无需登录，本版本增加了用户鉴权，默认增加admin用户，未登录不能操作任何页面*

## 1.1 特性清单

| IR编号 | 特性名称          | 特性描述                                                                                                         | 开发团队 | 备注  |
| ---- | ------------- | ------------------------------------------------------------------------------------------------------------ | ---- | --- |
| IR-3 | 平台基础能力-用户管理功能 | 为容器平台提供用户管理功能，当前仅支持容器平台管理员用户的操作。容器平台部署成功后，自动创建容器平台管理员用户与初始随机登录密码。 容器平台管理员用户首次登录后强制修改密码，之后才能对平台进行操作，具有所有操作权限。 | 平台组  |     |

  | 验证修改密码的响应时间不超过1s                        | 通过在页面打开f12查看修改密码请求的响应时间                                   | 不超过1s                               ||
  | 不同ip下同时对admin用户的密码进行修改                  | 在两台机器上都用admin登录，在两台机器上同时修改密码，查看密码生效情况                     | 根据接口响应先发送请求的修改成功，后发送请求的修改失败，并提示失败原因 ||
  | 不同ip下，其中一个机器对admin用户的密码进行修改，查看另一个机器上的影响 | 在两台机器上都用admin登录，在机器A上修改密码，查看对机器B的影响                       | 机器B会先正常操作，等机器B退出登录后，再次登录需要使用新的密码    ||

用户鉴权模块接口主要为登录鉴权和修改密码核心接口，需通过接口自动化测试快速检测功能接口是否正常运行。在自动化测试设计过程中，详细理解接口文档给出的接口定义、请求参数、响应格式、各错误状态码等信息，保证在写用例的过程中，尽量全面覆盖各种情况。
