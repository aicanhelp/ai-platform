# clusterAPI-25.06 测试方案

# 1. 特性描述  

ClusterAPI-25.06 提供集群生命周期管理功能，支持集群创建/扩容的前置校验及扩展组件离线安装能力。核心能力包括：  

- **前置校验**：覆盖节点IP重复性、SSH连通性、集群名称唯一性等场景校验，阻断非法操作。  
- **扩展组件离线部署**：支持通过全量/自定义离线包安装扩展组件（NPU管理、NUMA亲和、日志组件等）至本地Harbor仓。

# 2. 特性分层测试方案  

## 2.1 总体方案  

- **测试目标**：  

  1. 验证集群创建/扩容时前置校验的准确性（IP重复、名称重复、SSH不可达等场景）。  
  2. 验证扩展组件离线安装功能的完整性和兼容性（全量包、自定义包、多架构支持）。  

- **时间进度**：  

  | 阶段     | 开始日期      | 结束日期      | 工作日 |
  | -------- | ------------- | ------------- | ------ |
  | 功能测试 | 2025年5月23日 | 2025年5月30日 | 6      |
  | 转测验收 | 2025年5月30日 | 2025年6月7日  | 7      |
  
- **重点/难点**：  

  - 前置校验需覆盖多因子组合场景（如IP重复+SSH不可达）。  
  - 离线安装需兼容ARM/X86架构及不同扩展组件版本。    


---

## 2.2 功能测试方案  

#### SR-2-6 前置校验模块覆盖测试

**需求描述**：
支持新增节点/集群时的前置校验逻辑，覆盖集群名称、节点IP、节点名称重复性、IP可登录性、必填字段完整性等场景

| 正交因子     | 取值                                                         | 交互策略 | 备注 |
| :----------- | :----------------------------------------------------------- | :------- | :--- |
| 操作场景     | 新增节点、新增集群                                           | 正交     |      |
| 集群名称     | 名称重复（与已有集群同名）、名称不重复                       | 正交     |      |
| 节点IP地址   | IP重复（同一集群内重复、跨集群重复）、IP不重复               | 正交     |      |
| 节点名称     | 名称重复（与已有节点同名、与同批次扩容节点同名）、名称不重复 | 正交     |      |
| 节点IP可登录 | 不可登录（虚假IP、SSH端口错误、账号错误、密码错误）、可登录  | 覆盖     |      |
| 信息完整性   | 必填字段缺失（IP未填、节点名称未填）、必填字段完整           | 覆盖     |      |



#### **SR-2-7 扩展组件离线安装验证**

**需求描述**：
支持扩展组件（如numa亲和、npu硬件管理、日志组件等）的离线安装，覆盖不同系统、架构、场景组合，确保镜像与chart包正确上传至本地harbor并正常部署。

| 正交因子     | 取值                                                         | 交互策略 | 备注 |
| :----------- | :----------------------------------------------------------- | :------- | :--- |
| 系统         | openEuler 22.03 LTS SP4、Ubuntu 22.04                        | 正交     |      |
| 架构         | arm64、X86                                                   | 正交     |      |
| 扩展组件类型 | 全量离线包、在离线混部、numa亲和、npu operator、openfuyao-ray、日志、多集群管理、自定义监控面板 | 正交     |      |
| 其他类型     | 扩展自定义、默认全量、全量离线包                             | 覆盖     |      |
