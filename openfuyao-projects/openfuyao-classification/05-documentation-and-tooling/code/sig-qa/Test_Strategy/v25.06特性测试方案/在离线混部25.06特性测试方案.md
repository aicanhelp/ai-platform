# 在离线混部特性测试方案



# 1. 特性描述

将在线业务和离线任务混合混部到相同物理资源上，通过资源隔离、调度等控制手段 , 充分使用资源，同时保证服务的稳定性，我们称这样的技术为“混部”。在openFuyao在离线混部和资源超卖的解决方案中，包括以下功能。

- 业务多QOS分级管理。
- 业务特性感知调度。
- 混部节点管理。
- 混部策略配置。
- 节点超卖资源管理和上报。
- 基于NRI机制的无侵入混部Pod创建和cgroup管理。
- 单机混部引擎（Rubick）和内核隔离技术多层次优化系统。

# 2. 特性分层测试方案

## 2.1 总体方案

- 测试目标：在离线混部v25.06所有需求

- 时间进度：

  | 开始日期  | 结束日期  | 工作日 | 阶段     | 备注 |
  | --------- | --------- | ------ | -------- | ---- |
  | 2025.6.23 | 2025.6.26 | 4      | 功能测试 |      |
  | 2025.6.23 | 2025.6.26 | 4      | 长稳测试 |      |
  | 2025.6.23 | 2025.6.26 | 4      | 性能测试 |      |

- 风险评估：可能存在开发交付延期，测试时间紧张

- 重点/难点：HLS级别为本次新增需要重点测试，包括其绑核和不绑核；混部监控内容比上个版本更详细，需要重点测试数据的正确性等。

- 待定事项：无

- 入口标准：

  1. 特性满足质量标准，达成需求设计要求目标

- 出口标准：

  1. 方案规划的测试活动涉及测试用例100%执行完毕
  2. 无block问题遗留，其它遗留问题要有相应规避措施或说明
