# 算力引擎测试方案

# 1. 特性描述

​     本特性包括算力引擎底座，以及一些具体的调优插件组合而成。算力引擎可以是目前业界成熟的调优技术，也可以是任何组织各样的调优技术整个到一起发布的调优插件，目前计划支持的KAE插件调优。

## 1.1 特性清单

| IR编号 | 特性名称         | 特性描述                                           | 开发团队 | 备注 |

|        | 算力引擎底座框架 | 在云原生领域整合各类调优插件，降低用户集成调优门槛 |          |      |
