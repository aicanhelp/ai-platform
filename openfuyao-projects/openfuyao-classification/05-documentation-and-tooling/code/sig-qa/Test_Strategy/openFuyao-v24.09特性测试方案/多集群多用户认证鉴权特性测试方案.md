# 多集群多用户认证鉴权特性测试方案

# 1. 特性描述

*openFuyao24.09版本在保持openFuyao24.06版本功能基础上一方面集成了多集群管理的基本能力,实现对跨集群资源管控，统一策略配置以及跨集群资源调度；另一方面也从单admin用户上发展为多用户容器平台，实现了多用户多角色功能*

## 1.1 特性清单

| IR编号 | 特性名称             | 特性描述                                                                                                         | 开发团队 | 备注  |
|------|------------------| ------------------------------------------------------------------------------------------------------------ | ---- | --- |
| IR-6 | 基于Karmada的多集群管理、多用户管理，用户分权分域以及认证鉴权能力 |  | 平台组  |     |
