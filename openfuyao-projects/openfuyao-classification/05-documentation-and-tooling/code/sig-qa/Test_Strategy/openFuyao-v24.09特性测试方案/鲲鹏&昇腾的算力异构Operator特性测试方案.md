# 鲲鹏昇腾的异构算力Operator特性测试方案

摘要：
在 Kubernetes 中支持 KAE、NPU 设备调度，需要做如下的工作：

- 节点上安装 KAE、NPU 驱动。
- 集群部署 NFD 服务，用于发现相关节点是否具有相关设备，给节点打标签。
- 集群部署 KAE-device-plugin、ascend-device-plugin。用于为调度到该节点的 Pod 分配设备。

如何需要监控集群硬件资源使用情况，可能还需要安装 ascend-npu-export 结合 Prometheus 输出 NPU 资源监控信息，基于此，需要开发一款工具(Operator)，用于自动化管理上面我们提到的这些组件。

- 通过如下命令检测 NFD 是否已具备：

  ```
  kubectl get nodes -o json | jq '.items[].metadata.labels | keys | any(startswith("feature.node.kubernetes.io"))'
  ```
  
  如果命令输出为`true`，则 NFD 已在集群中运行
