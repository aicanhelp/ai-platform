# Security Committee

This document mainly introduces the responsibilities, organizational structure, and operation mode of the openFuyao Security Committee, as well as the relevant processes it is responsible for.

## Security Committee (SC) Mission

The openFuyao Security Committee (SC) is responsible for receiving and responding to openFuyao-related security issue reports, providing community security guidance, conducting community security governance, and providing openFuyao users with the most secure products and development environment.

## Work Responsibilities

+ Assist with vulnerability fixes: Ensure timely fixes for known vulnerabilities. Help user systems perform vulnerability fixes before becoming attack victims, including providing relevant vulnerability detection and fix tools.
+ Respond to security issues: Respond to reported security issues, track the handling progress of security issues, and follow the security issue disclosure policy to disclose and announce security issues within the community.
+ Security coding rules: Popularizing security coding knowledge is the goal of the security team. The security team will strive to create documentation or develop tools to help development teams avoid common pitfalls in the software development process. The security team will also try to answer any questions encountered during development and use.
+ Participate in code reviews: The security team hopes to help teams discover vulnerabilities in code in advance through code reviews.
