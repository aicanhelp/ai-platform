# sig-ub-enable

UB Enable SIG 旨在构建一个开放、高效的面向UB超节点的AI云原生使能体系。本SIG聚焦UB超节点**K8s资源调度增强**、**应用场景加速**、**开发者工具链**三大领域，针对UB超节点的高速通信、资源池化等关键能力，探索资源利用率和业务性能提升方面新的技术范式，推动社区在该领域的技术演进。

## 工作范围

- **基于超节点的K8s资源调度增强**：构建模块化、高性能、K8s生态兼容的云原生组件，使能容器业务可以使用UB超节点能力。
- **基于超节点的应用场景加速**：针对关键应用场景，探索基于UB超节点的创新架构和优化范式，带来性能和效率大幅度提升。
- **超节点专用开发工具链**：提供UB超节点开发者全生命周期使能服务，做到在开发者机器上实现UB亲和开发/编译/测试/性能定性分析。

## 技术协同

### 与openFuyao其他SIG能力协同

- **资源调度使能**：协同容器编排引擎SIG，扩展K8s调度组件能力，感知UB超节点的共享拓扑关系，进行相关Pod的调度选择。
- **基于超节点的应用场景加速**：协同AI推理SIG、大数据SIG、容器编排引擎SIG，探索UB应用加速创新范式。
- **超节点专用开发工具链**：协同基础设施SIG，针对UB超节点使能场景，持续优化开发者工具链和软件工程能力。

#### 与业界开源技术方案协同

- **基于超节点的K8s资源调度增强**：Kubernetes原生的多样化资源管理与调度方案。
- **基于超节点的应用场景加速**：协同CXL、UALink总线，协同各场景应用上游社区等。
- **超节点专用开发工具链**：基于开源项目QEMU构建UB超节点仿真能力；基于Lmbench内存测试项目增加UB支持等。

## 2026年规划

### 1、基于超节点的K8s资源调度增强

- **KT1：容器集群释放UB高带宽/低时延能力**
	- （2026 Q1）UB CNI插件（Villus 2.0）：基于URMA语言通信和UB网络硬件，构建UB网卡和DPU网卡的CNI插件，连接容器网络与UB网络，实现低时延高性能通信。
    - （2026 Q2）UB CSI插件：通过灵衢UB平等互联架构SSU直通，构建SSU存储的CSI插件，容器存储动态分配和挂载。

- **KT2：基于UB增强K8s调度，提升资源利用率**
	- （2026 Q1）容器热迁移：基于UB大带宽/内存池化和内核态CRIK能力，叠加K8s拓扑感知调度，Pod迁移中断时间小于0.5s。
    - （2026 Q2）拓扑感知调度：池化资源度量和指标采集，基于负载拓扑感知调度、装箱优化等多种亲和调度算法，均衡系统资源。
     - （2026 Q2）Remote-Fork：基于UB共享内存实现的Remote-Fork快速拉起容器，实现百毫秒级容器冷启动，提升系统可用性、弹性效率和资源利用率。
