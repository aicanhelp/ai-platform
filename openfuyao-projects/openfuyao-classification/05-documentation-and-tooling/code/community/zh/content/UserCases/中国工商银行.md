# 中国工商银行

集群级+节点级全场景NUMA亲和方案，助力快捷支付应用场景降低时延。

## 背景

随着金融行业交易竞争力、合规与安全等要求的日益提高，低时延已成为高频量化交易、算法交易、性能安全合规的关键。如何面向国产算力集群，有效打造低时延业务调度方案至关重要。因此，工商银行软件开发中心携手openFuyao，基于国产鲲鹏算力集群，共同打造金融低时延集群调度方案。

## 解决方案

<center>金融低时延集群调度方案</center>

![image](./figures/gonghang.png)

- 基于NUMA拓扑的集群级亲和调度：支持numa-aware调度策略，实现single-numa-node、best-effort、restricted等拓扑管理策略的亲和调度。
- 节点级资源分配优化：
  1. 支持NUMA Distance最优分配策略，提升跨NUMA场景性能。
  2. 支持基于openEuler的NUMA FAST-POD间亲和感知，对Pod进行NUMA亲和优化，提升性能表现。

## 应用价值

- 业务低时延：通过集群级、节点级两级NUMA亲和调度，支持不同优先级业务均能实现低时延能力，优先保障业务竞争力与合规安全需求。
- 资源高利用率：在保障业务低时延高性能的同时，通过动态亲和感知调度，有效避免资源碎片化问题，确保业务集群高资源利用率。
