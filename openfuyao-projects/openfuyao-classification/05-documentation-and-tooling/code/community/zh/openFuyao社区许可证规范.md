# openFuyao社区许可证规范

所有openFuyao社区仓库代码需要遵循木兰宽松许可证，第2版（MulanPSL2）。许可证详情参见[官方文档](http://license.coscl.org.cn/MulanPSL2)说明。

## 社区开发者许可证使用介绍

所有新建仓库需要拷贝本仓库中的[LICENSE文件](./LICENSE)到新建仓库的根目录，表明该新建仓库的License为MulanPSL2。

任意仓库内新建文件，需要在源文件头部注释中添加如下许可证信息，表明此文件的License信息。Yaml文件与Markdown文件暂时不用添加License信息。
