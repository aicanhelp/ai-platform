# openFuyao 目录使用规范

本文档用于指导用户在安装、运行、升级和卸载openFuyao平台时，正确使用宿主机目录。

遵循该目录规范有益于：

- 降低系统盘被写满的风险；
- 提升问题排查效率（日志、配置、数据位置清晰）；
- 减少升级和卸载过程中的目录残留或误删风险。

> 适用对象：平台安装人员、运维人员、集群管理员。

## 目录使用原则

本规范遵循以下核心原则：

**原则1：openFuyao核心组件的目录归一**

所有openFuyao平台自身的组件的配置、日志、二进制文件统一归集到专用目录下。

**原则2：openFuyao自研组件的目录归一**

对于平台附带安装的自研组件（如bke、bkeagent等工具），同样遵循归一化原则。

**原则3：其他的开源组件保持不变**

对于Kubernetes、containerd、etcd、CNI等开源生态组件，严格遵循其社区约定的标准路径，不进行目录归一。

## 目录规范

针对日志、配置、二进制和运行时数据，分别给出规范的目录路径。

#### 日志目录

- **平台自有日志**集中管理，归一到`/var/log/openFuyao/`，便于排障与归档。
- **Kubernetes 标准日志**路径保持不变，保证`kubectl logs`、日志采集链路与运维习惯不受影响。

**表1** 日志目录规范路径

| 类别             | 规范路径                                                     | 说明                                               |
| :--------------- | :----------------------------------------------------------- | :------------------------------------------------- |
| 容器标准输出日志 | `/var/log/pods/`、 `/var/log/containers/`                     | 保持默认，确保`kubectl logs`与现有采集链路可用。 |
| 容器文件日志 | `/var/log/openFuyao/openfuyao-system-controller`、`/var/log/openFuyao/apiserver/` | 存放容器文件日志。                                 |
| 宿主机二进制日志 | `/var/log/openFuyao/bkeagent.log*`、`/var/log/openFuyao/bke.log` | 存放openFuyao、bkeagent等宿主机进程日志。        |

#### 配置目录

- **平台配置**统一收敛到`/etc/openFuyao/`，降低配置分散带来的维护成本。
- **系统与社区组件配置**保持默认路径，避免生态兼容问题。

**表2** 配置目录规范路径

| 类型               | 规范路径                                                     | 说明                                 |
| :----------------- | :----------------------------------------------------------- | :----------------------------------- |
| 平台配置/证书      | `/etc/openFuyao/{addons、certs}`                             | 平台核心配置、证书统一存放。         |
| HA配置            | `/etc/openFuyao/{haproxy、keepalived}`                       | 存放haproxy/keepalived相关配置。 |
| Agent工作配置     | `/etc/openFuyao/bkeagent/`                                   | 存放bkeagent本地工作配置。         |
| 系统及社区组件配置 | `/etc/hosts`、`/etc/systemd/system/`、`/etc/kubernetes/`、`/etc/containerd/`、`/etc/rancher/k3s` | 保持默认路径。|
| bke安装部署配置   | `/bke/cluster`、`/bke/tmpl`                                  | 安装配置文件。                       |

>  ![输入图片说明](public-figures/icon-note.gif) **说明：**
>
>  `/bke`作为安装工作目录，和平台运行时配置分离，便于安装过程隔离与卸载阶段分步清理。

#### 二进制目录

- **平台工具**入口稳定，便于脚本调用与版本替换。
- **核心运行时工具**遵循发行版与社区约定，避免改路径后引发兼容问题。

**表3** 二进制目录规范路径

| 类型         | 规范路径                                                     | 说明                      |
| :----------- | :----------------------------------------------------------- | :------------------------ |
| 平台管理工具 | `/usr/local/bin/bke`、`/usr/local/bin/bkeagent`              | 平台工具统一入口。   |
| 安装依赖CLI | `/usr/local/bin/helm`、`/usr/local/bin/cfssl`、`/usr/local/bin/yq` | 保持默认路径。   |
| 集群核心工具 | `/usr/bin/containerd`、`/usr/bin/ctr`、`/usr/bin/crictl`     | 保持系统/发行版默认位置。 |

#### 运行时数据目录

运行时数据目录是容量增长最快、最影响节点稳定性的部分，需重点关注：

- `/var/lib/containerd`与`/var/lib/kubelet`会随着镜像、容器和业务负载持续增长。
- `emptyDir`、镜像缓存、容器可写层均会放大磁盘压力。

**表4** 运行时数据目录规范路径

| 类型           | 规范路径                                                     | 说明                                |
| :------------- | :----------------------------------------------------------- | :---------------------------------- |
| 控制面状态数据 | `/var/lib/openFuyao/etcd`                                    | openFuyao内置控制面etcd数据目录。 |
| 节点运行时数据 | `/var/lib/containerd`、`/var/lib/kubelet`、`/var/lib/cni`、`/var/lib/calico`、`/var/lib/nerdctl` | 保持默认路径。                      |
| 引导集群数据   | `/var/lib/rancher/k3s`                                       | 引导集群目录。                      |
| bke工作数据   | `/bke/volumes`、`/bke/mount`                                 | bke安装数据。                       |

## 推荐磁盘分区与容量

**表5** 安装部署推荐分区和最小容量

| 挂载点            | 承载目录                               | 最小容量（GB） | 共部署最小容量（GB） | 说明                                               |
| :---------------- | :------------------------------------- | :------------- | :------------------- | :------------------------------------------------- |
| 系统盘 `/`        | `/usr`、`/etc`、`/var`、`/opt`、`/bke` | 25             | 40                   | 系统程序、配置、平台日志与安装工作区。             |
| 数据盘 `/var/lib` | `/var/lib/*`                           | 40             | 60                   | 运行时高增长目录（containerd、kubelet、etcd等）。 |

**注意事项：**

- 表中“最小容量”是引导集群和管理集群分开部署的最低建议值，共部署时参考“共部署最小容量”。
- /var/lib必须挂载独立数据盘，否则安装前置检查应阻断部署。
- 建议根据实际情况预留20-30%空间，磁盘长期使用率控制在60%以下，避免突发数据增长导致磁盘占用过高。

| 系统盘 (/)          | `/etc/openFuyao/`               | 平台配置与证书       | 存放平台配置、证书、HA相关配置。                  |
| 系统盘 (/)          | `/etc/`                         | 系统/核心组件配置    | 保持生态约定路径，不做迁移。                       |
| 系统盘 (/)          | `/bke/`                         | 安装工作空间         | 与平台运行配置解耦，便于安装重装与问题定位。       |
| 系统盘 (/)          | `/var/log/openFuyao/`           | 平台与组件日志       | 归一化平台日志（宿主机日志、组件文件日志）。       |
| 系统盘 (/)          | `/var/log/`                     | 容器标准输出日志     | 保持Kubernetes默认日志路径。                     |

| 数据盘 (`/var/lib`) | `/var/lib/{cni、calico、nerdctl}` | 网络与运行时辅助数据 | 保持原路径，统一纳入数据盘容量管理。               |
| 数据盘 (`/var/lib`) | `/var/lib/rancher/k3s`          | 引导集群数据         | 引导阶段目录，保持不变。                           |
