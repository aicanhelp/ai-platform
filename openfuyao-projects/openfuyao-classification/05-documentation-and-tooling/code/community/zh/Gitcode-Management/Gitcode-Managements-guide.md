# openFuyao Gitcode组织管理指南

openFuyao项目使用Gitcode来管理团队和代码。本指南包含如何在openFuyao社区准则的基础上运作这些组织。

## 服务承诺

Gitcode管理团队将竭尽所能提供以下的服务水平：

- 新组织创建在所有成员资格满足以后的72小时内处理
- Repository的新建或迁移请求在PR提交后的72小时内回复。这个过程可能需要申请人提供一些信息，所以可能会花费一些时间。但所有条件一旦满足，Gitcode管理团队会在72小时内完成响应repository的处理
- PR提交后的72小时内，会有所答复。问题解决的时间会按照问题的具体情况有所不同。

如果您需要上报紧急请求，请直接联系[openFuyao基础设施团队](<mailto:infra@openeuler.org>)快速寻求帮助

##  openFuyao的组织说明

- [openFuyao](https://gitcode.com/openFuyao)：主要用于存放源码类项目


## 将外部代码转移到openFuyao组织中

由于开源许可和CLA等问题，在将代码转移到openFuyao管理之前，需要进行一些调查，请先向[技术委员会](/zh/technical-committee/README.md)提交申请。

## 创建项目及代码仓

- 创建新团队或项目请向技术委员会提交申请，请参考[如何申请一个SIG](/zh/technical-committee/governance/README.md)
