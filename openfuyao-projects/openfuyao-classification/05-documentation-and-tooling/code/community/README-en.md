# Organization Introduction

openFuyao is an open source community dedicated to software technology innovation for general-purpose and intelligent computing clusters. It is committed to providing diverse computing cluster software ecosystems for the world, unleashing infinite value of intelligence. It aims to gather partners and developers through open collaboration, build diverse computing internet scheduling capabilities, achieve ultimate release of cluster computing power, incubate key software root technologies based on clusters, establish unified and open technical standards, and jointly create an efficient and innovative computing cluster community.
