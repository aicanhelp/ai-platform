# sig-container-platform

Welcome to sig-container-platform.

## 工作目标和范围

简化部署和管理流程，优化容器编排、调度、存储、网络等核心功能，增强多租户、可观测性、灾备等企业级特性，致力于推动容器技术的创新、标准化和落地实践，以赋能企业数字化转型和云原生生态发展。

## 组织例会

sig-container-platform是开放的，我们的用户、贡献者和维护者不断改进它。正是因为您，我们才能够构建出更稳定、易用的超大规模集群。加入我们！

- 我们会在会议上分享最新的进展、解决项目问题、演示新功能、讨论未来规划等，加入sig-container-platform的例会：

    - 会议时间：按需展开 周四 09:15~10:15
    - 会议链接：[在openFuyao官网社区会议中获取](https://www.openfuyao.cn/zh/meeting/)
    - 会议记录：[会议纪要](https://etherpad.openfuyao.cn/p/sig-Container-Platform)
