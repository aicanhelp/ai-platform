# openFuyao 技术委员会 (Technical Committee)

## 简介

openFuyao 技术委员会（Technical Committee，简称 TC）是 openFuyao 开源社区的技术领导机构，负责社区的技术发展方向规划、关键技术决策以及技术生态建设。

openFuyao 是面向通算和智算集群软件技术创新的开源社区，致力于通过开放协作汇聚伙伴与开发者，构建多样化的算力集群软件生态，提升集群的算力利用效率与安全性，并推动相关软件根技术及统一技术标准的发展。

## 技术委员会职责

技术委员会作为社区的技术领导机构，其主要职责包括：

1. **技术决策**：拥有社区技术决策的最终裁决权，决策社区技术的发展愿景和方向。
2. **SIG 管理**：决策社区 SIG（特别兴趣小组）的成立、撤销、合并等事务，解决 SIG 组之间的协作冲突，辅导、审视和监督 SIG 组的日常运作。
3. **版本质量**：落实社区日常开发工作，保证 openFuyao 社区发行版高质量发布。
4. **技术创新**：引导社区在 AI 云原生、算力调度、异构计算、集群管理等领域的技术创新，保证社区具有持续的技术竞争力。
5. **生态建设**：引导社区建立原创性开源项目，持续构建社区技术影响力。
6. **标准制定**：推动统一、开放的技术标准制定，促进算力集群软件生态健康发展。

## 会议制度

### 例会时间

技术委员会例会时间在北京时间，每双周周五下午14:15召开公开的例行线上会议。

### 会议通知

在会议召开前通过邮件通知订阅邮件列表的成员，会议通知应当包括召开的地点、日期、时间、方式和会议议题以及可用的参考来源，以便委员对会议内容获取相关信息进行准备。

也可通过openFuyao官网[线上会议](https://www.openfuyao.cn/zh/meeting/)查看详情。

### 会议形式

会议为公开会议，任何社区成员都可以参加会议，表达技术观点但无投票权利。

### 决策机制

- 技术委员会会议须有三分之二以上（含）的委员出席为有效会议。
- 所有决议均需要在有效的例会进行投票表决，投票为公开记名投票。
- 投票分为赞同票、反对票和弃权票，只有三分之二以上（含）的与会委员且超过全体委员会的二分之一投赞同票，决议才能通过。
- 技术委员会会议讨论未尽的事宜，可在技术委员会公开邮件列表通过邮件继续讨论。
