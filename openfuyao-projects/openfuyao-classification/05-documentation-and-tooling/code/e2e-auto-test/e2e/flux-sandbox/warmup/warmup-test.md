## 说明

- **子系统边界**：warm 子系统内嵌于控制器进程（非独立 Deployment），四个预热接口（创建任务、任务进度、缓存详情、存储详情）与控制器共用 8080 端口（--http-addr）；控制面/数据面其余功能由 `../controlplane`、`../dataplane` 套件覆盖。
- **外部依赖**：前置条件为 flux 相关组件（controller、CRD、RBAC）已部署；套件自动创建测试专用 PostgreSQL（并执行 `testdata/config/controller/warm-migrations/0001_warm.sql`）、fake MoonCake etcd 和 fake E2B。
- **启用方式**：warm 默认关闭；启用需 `--warm-enabled=true` 并补齐 `--warm-postgres-dsn`、`--warm-etcd-endpoints`、`--warm-e2b-api-endpoint`、`--warm-superpod-ids`，缺失任一控制器 fail-fast 拒绝启动（WARM-E2E-029）。
- **计时加速与门控**：套件以 `--warm-task-stale-timeout=30s --warm-etcd-staleness=10s` 及 fake E2B 2s 派发延迟加速执行，全套约 10 分钟；`WARM_E2E_SCALE`（021 万级规模）与 `WARM_E2E_DESTRUCTIVE`（025/026 停依赖服务）默认开启，可用 `0/false/no/off` 关闭。WARM-E2E-021 已由10万规模降级为1万（P2），10万全量验证转入性能/规模专项。
- **自动化环境**：套件在独立命名空间 `flux-warm-e2e` 部署测试依赖（PostgreSQL+PVC、fake MoonCake etcd、可编程 fake E2B——支持 always/once/off 故障注入、派发延迟调节、请求日志与 etcd 上报 backdate/pause），并 patch 现成 controller 的 warm 参数，结束后恢复；本地端口 18085（warm API）/15432（PG）/12379（etcd）/12380（fake E2B admin）。
- **验证记录**：2026-09-15 完整运行一轮：29 通过 / 0 失败 / 0 跳过。
- **实现差异**：多处预期与设计文档（`docs/design/0004-沙箱快照预热.md`）不一致，均以实现为准，详见各行备注（task_id 实际格式、任务级 SUCCEED/快照级 SUCCESS、summary 汇总字段、size_bytes=0、E2B 走 HTTP POST /v1/warm-snapshot、etcd 按 updated_at 判过期等）。
