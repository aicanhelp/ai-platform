## 说明

- **数据面边界**：flux-sandbox-agent（HTTP API、SandboxManager、Runtime）、sandbox-watcher（Fast/Slow path、cleanup）。控制面（controller/scheduler）不在覆盖范围。
- **运行时**：默认 containerd（k8s 环境）。CRI 路径在无 shim 环境下由 UT 覆盖，具备环境时补 e2e。
