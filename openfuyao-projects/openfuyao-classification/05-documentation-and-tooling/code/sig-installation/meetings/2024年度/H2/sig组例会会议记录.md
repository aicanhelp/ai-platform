# 9月6日 例会记录

## 与会人：马华兵、陈传雨、高鹏、崔雷雷、张帆、史子龙

## 会议纪要

1、博云侧演示bke工具使用，并部署在、离线单节点集群  
2、博云侧针对openFuyao侧提出的问题进行解答  

- bke工具集支持k8s升级，但不支持降级，非高可用集群升级过程中业务会中断，高可用集群升级过程中对业务影响较小或无影响  
- bke工具进行k8s升级时无指定的版本路径，只要镜像仓内有对应镜像文件即可进行升级操作  
- 使用bke部署工具部署的集群可以纳管非bke工具部署的集群，但是不支持对非bke工具部署的集群进行升级、扩容、缩容、销毁操作  
- bke目前已经支持openEuler 22.03 amd64，计划下周支持openEuler 22.03 arm64  
- bke使用密码访问集群节点，不支持使用密钥访问，但仅使用一次密码，后续再访问集群节点均通过agent连接  
- bke完成集群部署后可部署插件，openFuyao管理面可以以插件形式部署到集群，但所部署插件均经过高度定制化处理  
- bke支持部署高可用集群，使用Keepalived和HaProxy实现高可用集群  
- 博云使用kubebuilder框架开发bke的operator
