# 通过前台（Web页面）删除业务集群

本文介绍在openFuyao管理面“集群生命周期管理”中删除业务集群。按业务集群的****部署方式**选择对应管理面登录地址，可详见下方[表1](#table12452)。

## 前提条件

- 确认待删除对象为**业务集群**，且业务已迁移或可接受不可恢复删除。
- 已阅读[集群卸载总览](./overview.md)。

## 按部署入口选择管理面

**表1** 业务集群部署方式与管理面对应关系<span id="table12452"></span>

| 业务集群部署方式 | 登录的管理面 | 地址 |
|:---|:---|:---|
| 由**引导集群**部署（在引导节点管理面创建） | 引导节点openFuyao管理面 | `https://<引导节点IP>:30010` |
| 由**管理集群**部署（在管理集群管理面创建） | 管理集群openFuyao管理面 | `https://<管理集群IP>:31616` |

菜单均为左侧导航**集群生命周期管理**。

> ![说明](./figures/icon-note.gif) **说明：**<br />
> 请到创建该业务集群时使用的同一管理面执行删除，避免进错入口。

## 操作步骤

1. 按上表登录对应openFuyao管理面。
2. 选择“集群生命周期管理”，进入集群列表。
3. 定位待删除的**业务集群**，在操作列选择“删除/卸载”。
4. 在确认对话框中核对集群名称后确认删除。
5. 返回列表，等待该集群从列表移除。

## 卸载成功示意

- “集群生命周期管理”列表中不再显示该业务集群。
