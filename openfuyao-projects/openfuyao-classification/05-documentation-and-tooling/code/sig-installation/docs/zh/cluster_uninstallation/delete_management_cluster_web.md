# 通过前台（Web页面）删除管理集群

本文介绍通过openFuyao管理面（Web页面）卸载管理集群。因节点代理bkeagent安装时前期侦听引导集群、之后切换为侦听管理集群自身，须分别在管理集群管理面与引导集群管理面执行删除操作，缺一不可。

> ![说明](./figures/icon-note.gif) **说明：**<br />
> 管理集群管理面（`:31616`）部署在管理集群上，随管理集群卸载会一并不可用。步骤1发起删除后，该管理面可能无法再登录，属于正常现象；最终以引导节点管理面（`:30010`）侧清理结果为准。

## 前提条件

- 删除前须能分别登录**管理集群**与**引导节点**的openFuyao管理面。
- 其下纳管的业务集群应已卸载或已迁移。
- 已阅读[集群卸载总览](./overview.md)。

## 操作步骤

1. 登录管理集群Web页面，删除集群。

   1.1 浏览器访问“https://<管理集群IP>:31616”，登录管理集群管理面。
   1.2 左侧导航选择“集群生命周期管理”。
   1.3 定位待删除的**管理集群**，在操作列选择“删除/卸载”。
   1.4 核对集群名称后，根据风险提示确认删除。删除开始后，该管理面可能中断或无法再访问，无需再依赖该管理面确认集群列表状态。

2. 登录引导集群Web页面，删除集群。

   2.1 浏览器访问“https://<引导节点IP>:30010”，登录引导节点管理面。
   2.2 左侧导航选择“集群生命周期管理”。
   2.3 定位同一管理集群对应条目，选择“删除/卸载”。
   2.4 核对名称后确认，等待集群列表中该集群条目被移除。

    > ![说明](./figures/icon-note.gif) **说明：**<br />
    > - 步骤1、步骤2均须完成；只执行其中一侧删除会导致另一侧残留对应集群对象。
    > - 两两侧列表中的集群名称可能略有差异，请按实际创建时的集群名称核对。
    > - 请先完成步骤1；若步骤1后 `:31616` 已不可用，直接继续步骤2。

## 卸载成功示意

- 管理集群管理面（`:31616`）无法再登录或访问。
- 引导节点管理面（`:30010`）“集群生命周期管理”中已无该管理集群。

## 后续说明

- 其他卸载方式与删除顺序见[集群卸载总览](./overview.md)。
- 引导集群卸载须放在最后，见总览中的引导集群卸载说明。
