# 通过前台（Web页面）缩容业务集群

集群缩容是指将已有的工作节点（Worker Node）从业务集群中移除，以释放计算资源。通过openFuyao管理面的集群生命周期管理页面，用户可以方便地在Web界面上完成业务集群的缩容操作。

## 前提条件

- 待缩容的业务集群状态为“健康”。在集群生命周期管理列表界面可查看集群状态，详情请参见[管理面安装业务集群](../cluster_installation_guide/service_cluster_installation/service_cluster_installation_on_the_management_plane.md)。
- 需在创建该集群时使用的引导节点或管理集群上进行缩容操作。
- 待删除的节点为工作节点（Worker Node），且节点上无关键业务运行，或已做好Pod迁移准备。

> ![输入图片说明](figures/icon-notice.gif) **须知：**
> 集群缩容操作必须在创建该集群时使用的引导节点或管理集群上进行，否则无法管理目标集群。

## 使用限制

- 缩容时仅支持删除工作节点（Worker Node），不支持通过Web页面删除Master节点。手动删除Master角色的`BKENode`资源会被Webhook校验拒绝，只有控制器发起的删除或节点处于Failed状态时才允许删除。
- 删除节点后将无法恢复，请谨慎操作。
- 集群处于扩容、安装、升级等非稳定状态时，不允许发起新的缩容操作。
- 待删除节点上的Pod将被强制驱逐或删除，请确保业务可接受节点下线。

## 操作步骤

1. 登录创建该集群时使用的引导节点或管理集群的openFuyao管理面。

   浏览器中输入“https://<引导节点或管理集群的登录IP地址>:<集群生命周期管理的web服务端口>”，输入用户名和密码登录集群生命周期管理页面。

   > ![输入图片说明](figures/icon-note.gif) **说明：**
   > - 通过引导节点登录时，Web服务端口默认为30010；通过管理集群登录时，web服务端口默认为31616。

2. 在openFuyao平台的左侧导航栏中选择“集群生命周期管理”。界面展示集群生命周期管理的列表信息，包括“集群名称”、“状态”、“节点数”等信息。

3. 在“集群生命周期管理”列表界面单击需要缩容的“集群名称”，进入“节点详情”界面。

4. 选择删除方式。

   **方式一：批量删除**

   1. 勾选“节点名称”前的复选框，选中需要删除的工作节点。

      > ![输入图片说明](figures/icon-note.gif) **说明：**
      > 控制平面节点（Master节点）的复选框为不可选状态，仅工作节点可被选中删除。

   2. 单击列表上方的“删除”。

   **方式二：单个删除**

   1. 在需要删除的工作节点所在行，单击“操作”列的删除图标。

5. 在弹出的“删除节点”确认窗口中，查看待删除的节点信息。

   窗口显示以下提示信息：
   - “删除节点后将无法恢复，请谨慎操作。”
   - “确定删除节点*节点名称*吗？”

6. 勾选“已了解此次删除不可撤销”复选框。

7. 单击“删除”，系统下发缩容任务。

   - 弹出“集群信息”日志窗口，实时展示缩容操作日志。
   - 返回集群生命周期管理列表界面，对应集群的“状态”列显示为“缩容中”。

8. 待“状态”列字段更新完毕，完成集群缩容。

   - 缩容成功：对应集群的“状态”列为“健康”。
   - 缩容失败：对应集群的“状态”列为“扩缩容失败”。

> ![输入图片说明](figures/icon-note.gif) **说明：**
> 缩容操作包括节点Drain、Pod驱逐、kubeadm reset等步骤，耗时较长，请耐心等待。在缩容未完成时，集群尚未稳定，请勿对集群进行其他操作。

## 状态说明

缩容过程中，集群状态变化如下：

| 状态 | 说明 |
|:----- |:----------- |
| 缩容中 | 工作节点正在从集群中移除，包括Pod驱逐、节点Drain、kubeadm reset等操作。 |
| 扩缩容失败 | 缩容过程中出现错误，节点未能成功移除。需要排查后重试。 |
| 健康 | 缩容完成，节点已成功移除，集群处于健康状态。 |

> ![输入图片说明](figures/icon-notice.gif) **须知：**
> 缩容失败后，集群状态显示为“扩缩容失败”。请参考[集群部署问题定位指导](../cluster_installation_guide/appendix/cluster_deployment_issue_diagnosis_guide.md)排查原因。

## 后续操作

完成集群缩容后，如需对集群进行扩容操作，请参见[通过前台（Web页面）扩容业务集群](./service_cluster_scale_up_web.md)。
