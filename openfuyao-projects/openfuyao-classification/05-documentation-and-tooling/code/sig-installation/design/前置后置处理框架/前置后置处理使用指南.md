# 前置/后置 处理使用指南

## 一、前置处理（Preprocess）使用指南

本文只介绍**前置处理的全局配置**用法，适用于所有节点统一执行脚本的场景。

---

### 1. 功能与执行时机

前置处理在集群部署流程的 `EnsureNodesEnv` 阶段执行。  
控制器会检查是否存在**全局配置**，若存在则对所有匹配节点下发内置命令 `Preprocess` 执行脚本。

---

### 2. 配置入口（全局配置）

仅需创建一个全局配置 `ConfigMap`：

- 命名空间：`user-system`
- 名称：`preprocess-all-config`
- 必须包含 `config.json`

`config.json` 格式：

```json
{
  "scripts": [
    {
      "scriptName": "init-os.sh",
      "order": 10,
      "params": {
        "HTTP_REPO": "http://repo.local"
      }
    }
  ]
}
```

字段说明：

- `scripts`：脚本列表（必填）
- `scriptName`：脚本 ConfigMap 名称（必须一致）
- `order`：执行顺序（从小到大）
- `params`：脚本参数（可选）

---

### 3. 脚本 ConfigMap 规格

每个脚本必须单独创建 `ConfigMap`，并满足以下要求：

- 命名空间：`user-system`
- 名称：与 `scriptName` 完全一致
- 标签：`bke.preprocess.script: "true"`
- `data` 中必须有**同名 key**，内容为脚本文本

示例（脚本 `init-os.sh`）：

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: init-os.sh
  namespace: user-system
  labels:
    bke.preprocess.script: "true"
data:
  init-os.sh: |
    #!/bin/sh
    echo "NODE_IP=${NODE_IP}"
    echo "HTTP_REPO=${HTTP_REPO}"
```

---

### 4. 参数渲染与校验规则

脚本支持 `${PARAM_NAME}` 变量替换：

- 内置参数：`NODE_IP`
- 自定义参数：来自 `params`

参数名规则：

- 必须匹配：`^[a-zA-Z_][a-zA-Z0-9_]*$`

参数值规则（白名单）：

- 仅允许：`a-z A-Z 0-9 - _ / . 空格 : # =`
- 单个值最大长度：**4096**

若参数不合法，该脚本会被**跳过**，不会导致整体失败。

---

### 5. 执行方式与落盘路径

控制器下发内置命令：

- `["Preprocess"]`

当未显式传入 `nodeIP` 时，插件会自动获取当前节点 IP（第一个非 localhost 的接口 IP）。

脚本渲染落盘路径：

- `/etc/openFuyao/bkeagent/scripts`

---

### 6. 使用示例（完整流程）

### 6.1 创建脚本 ConfigMap

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: init-os.sh
  namespace: user-system
  labels:
    bke.preprocess.script: "true"
data:
  init-os.sh: |
    #!/bin/sh
    echo "NODE_IP=${NODE_IP}"
    echo "HTTP_REPO=${HTTP_REPO}"
```

### 6.2 创建全局配置 ConfigMap

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: preprocess-all-config
  namespace: user-system
data:
  config.json: |
    {
      "scripts": [
        {
          "scriptName": "init-os.sh",
          "order": 10,
          "params": {
            "HTTP_REPO": "http://repo.local"
          }
        }
      ]
    }
```

应用以上两个 `ConfigMap` 后，所有符合条件的节点都会在 `EnsureNodesEnv` 阶段执行 `init-os.sh`。
